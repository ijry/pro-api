# 1 / 目标与范围

## 1.1 一句话定位

**在 M0 已经搭好的 Vue3 + TS + UnoCSS 骨架(只有空 `Home.vue` + `Button.vue` + `Card.vue`)之上,补全 M1 阶段对外发布"测试版"必备的全部用户前台页面 + 原子组件 + 业务组件 + API 调用层 + Pinia stores + 路由 + i18n + 测试**。

完成后,普通用户在浏览器中可以:**注册 → 登录(密码 / 邮箱码 / GitHub OAuth)→ 进控制台看余额 / 今日消费 / 最近调用 → 创建并复制 API 令牌 → 用 curl/SDK 接入 → 看消费日志 → 浏览模型广场 / 公告 → 申请手动充值 / 兑换兑换码 → 管理 GitHub 绑定 / 改密码 / 切换主题语言 → 退出**。

## 1.5 关键决策

| 维度 | 决策 |
|---|---|
| 路由 | `unplugin-vue-router` file-based(路线图 §6.3) |

| 表单校验 | 本地 `useForm` composable + zod-light 规则(不引 Vee-Validate 等重型库) |
| markdown(公告详情) | `markdown-it` + 一个 `sanitize` 钩子;不允许 raw HTML |
| 代码高亮(快速接入) | `highlight.js` 仅按需加载 `bash` / `python` / `js`(`languages/{bash,python,javascript}` 子模块) |
| 主题 | 默认 dark(M0 已有 `<html class="dark">`),用户可切换 light;`useAppStore.theme` 持久化 |
| 语言 | zh / en,默认 zh;`useAppStore.locale` 持久化 |
| Cookie / CSRF | 后端 [M1-02](./2026-05-21-里程碑1-02-用户与鉴权-设计稿.md#41-csrf-双-cookie-法) 用双 cookie 法;前端 axios 自动读 `document.cookie` 中的 `proapi_csrf` 注入到 `X-CSRF-Token` 头 |
| `/v1` 接入 | 用户接入 `/v1/*` 是用 `pa-xxx` API 令牌,前端不直接调,**用户复制令牌后用 curl / SDK 调** |
| 表格 vs 卡片 | M1 全部 list 优先 **list-of-cards**(令牌列表 / 充值历史 / 公告 / 模型广场);**仅日志页用真表格**(列多,密度要求高) |
| 组件库 | shadcn-vue **风格** 自组装(M0 决策);不引 shadcn-vue npm 包,所有原子组件手写 UnoCSS |
| 图标 | Lucide(via `@iconify-json/lucide`,UnoCSS preset 已挂)— `i-lucide-<name>` class |
| 二次确认 | 破坏性操作(删令牌 / 解绑 OAuth / 取消充值申请)用 `<Dialog>` 二次确认 |
| 错误处理 | 业务错误(40xxx)直接 toast;`401 / CodeNotLoggedIn` 跳 `/login?redirect=...`;`401 / CodeSessionExpired` 跳 `/login?reason=session_expired`;`429` toast + 启动 `Retry-After` 倒计时按钮;`5xx` toast "服务异常,请稍后" |
| time format | 优先用 `date-fns` + `date-fns/locale/{zh-CN,en-US}`;不引 dayjs |
| 节流 / 防抖 | `composables/useDebounced.ts` / `useThrottled.ts` 自写,< 30 行 |

# 2 / 完整路由表

> 入口骨架由 M0 已建(`web/user/src/router/index.ts`)— 现仅含 `/` 与 fallback。本 spec **改造为 file-based + 全量路由 + 守卫**。

## 2.1 路由策略

启用 [unplugin-vue-router](https://github.com/posva/unplugin-vue-router):

- 在 `web/user/src/pages/` 下每个文件自动生成路由
- 文件名约定:`pages/<segment>/<segment>.vue` → `/segment/segment`,`[id].vue` → 动态参数
- meta 通过 `<route lang="json">` SFC block 写入(unplugin-vue-router 支持)
- 路由命名自动按文件路径生成

## 2.3 `<route>` SFC block 约定

每个页面顶部:

```vue
<route lang="json">
{
  "name": "tokens",
  "meta": { "auth": true, "title": "nav.tokens", "layout": "app" }
}
</route>
```

`meta.layout` 取值 `"app"` / `"auth"`,App.vue 根据其分发到 `<AppLayout>` 或 `<AuthLayout>`(详见 §3)。

## 2.4 路由守卫

`web/user/src/router/index.ts`(改造后):

```ts
import { createRouter, createWebHistory } from 'vue-router'
import { routes } from 'vue-router/auto-routes'  // unplugin-vue-router 注入
import { useAuthStore } from '@/stores/auth'

export const router = createRouter({ history: createWebHistory('/'), routes })

router.beforeEach(async (to, from) => {
  const auth = useAuthStore()
  // 进入需登录路由前,确保已加载 user
  if (to.meta.auth) {
    if (!auth.user) {
      try { await auth.refresh() } catch { /* fall through */ }
    }
    if (!auth.user) {
      return { name: 'login', query: { redirect: to.fullPath } }
    }
  }
  // 已登录用户访问 login/register/forgot 直接跳回首页
  if (!to.meta.auth && auth.user && ['login', 'register', 'forgot'].includes(to.name as string)) {
    return { name: 'home' }
  }
})

router.afterEach((to) => {
  // 标题:i18n.t(meta.title) + " · proapi"
  const title = to.meta.title as string | undefined
  document.title = title ? `${i18n.global.t(title)} · proapi` : 'proapi'
})
```

> `auth.refresh()` 内部调 `GET /api/user/profile`;未登录返回 401 → 抛错 → 路由跳 login。

`auth.refresh()` 也在 App 启动时执行一次(SPA cold start),见 §8.1。

## 2.5 navigationFailures

监听 `router.onError`,把非 404 类错误打到 Sentry(M2 接);M1 仅 `console.error`。

## 2.6 路由级 lazy

`unplugin-vue-router` 默认生成 dynamic import;无需手动。

### 4.2.5 表单校验 helper

`composables/useForm.ts`(详细在 §11):

```ts
const form = useForm({
  initial: { name: '', quota_limit: null, allowed_models: [], allowed_ips: [], rpm_limit: 0, tpm_limit: 0, expires_at: null },
  rules: {
    name: (v) => !v ? t('errors.required') : v.length > 64 ? t('errors.too_long') : '',
    quota_limit: (v) => v != null && v < 0 ? t('errors.non_negative') : '',
    allowed_models: (arr) => arr.find((s: string) => !/^[a-zA-Z0-9._\-*]{1,128}$/.test(s)) ? t('errors.bad_model_pattern') : '',
    allowed_ips: (arr) => arr.find((s: string) => !isValidCIDR(s)) ? t('errors.bad_cidr') : '',
    expires_at: (v) => v != null && new Date(v).getTime() < Date.now() + 60_000 ? t('errors.expires_too_soon') : '',
  },
})
// form.values / form.errors / form.validate() / form.touch() / form.reset()
```

## 4.12 OAuth 回调页

- path: `/oauth/:provider/callback`
- file: `web/user/src/pages/oauth/[provider]/callback.vue`

```vue
<script setup lang="ts">
import { onMounted } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { useAuthStore } from '@/stores/auth'

const route = useRoute()
const router = useRouter()
const auth = useAuthStore()

onMounted(async () => {
  // 后端 302 来此,但 callback 主要由后端处理。
  // 此页面在 ?error=... 时显示错误,正常情况下后端已 302 到 /
  // 如果后端通过 query 传递结果(M1-02 决策为 302,但 OAuth 错误可能 302 到此页)
  const err = route.query.oauth_error as string
  if (err) {
    router.replace({ name: 'login', query: { oauth_error: err, oauth_message: route.query.oauth_message } })
    return
  }
  // 否则,backend 302 时已 set cookie;刷新 store 后跳目标
  await auth.refresh()
  router.replace((route.query.redirect as string) || '/')
})
</script>

<template>
  <div class="text-center p-8">
    <div class="i-lucide-loader-2 animate-spin text-3xl"/>
    <p class="text-fg-muted mt-3">{{ t('auth.oauth.processing') }}</p>
  </div>
</template>
```

> 实际后端 (M1-02 §5.1.9) 默认 302 到 `/` 或 `state.payload.redirect`,**不会**走该页。此页作为防御性兜底(若有 SDK 错把 callback URL 配到前端域)。

```ts
// src/api/http.ts
import axios, { type AxiosError, type AxiosResponse, type InternalAxiosRequestConfig } from 'axios'
import { useToast } from '@/composables/useToast'
import { i18n } from '@/i18n'
import { useAppStore } from '@/stores/app'
import { useAuthStore } from '@/stores/auth'
import { router } from '@/router'

/** 后端 JSON 错误结构(与 M1-01 ErrorResponse "json" 对齐) */
export interface ApiErrorBody {
  code: number
  message: string
  details?: Record<string, unknown> | null
}

export class ApiError extends Error {
  code: number
  details: Record<string, unknown> | null
  status: number
  constructor(body: ApiErrorBody, status: number) {
    super(body.message)
    this.code = body.code
    this.details = body.details ?? null
    this.status = status
  }
}

export const http = axios.create({
  baseURL: import.meta.env.VITE_API_BASE || '/',
  timeout: 30_000,
  withCredentials: true,
})

// 请求拦截:注入 CSRF 与 Accept-Language
http.interceptors.request.use((cfg: InternalAxiosRequestConfig) => {
  const csrf = readCookie('proapi_csrf')
  if (csrf && needCSRF(cfg.method)) {
    cfg.headers.set('X-CSRF-Token', csrf)
  }
  const app = useAppStore()
  cfg.headers.set('Accept-Language', app.locale === 'en' ? 'en' : 'zh-CN')
  return cfg
})

// 响应拦截:错误归类
http.interceptors.response.use(
  (res: AxiosResponse) => res,
  (err: AxiosError<ApiErrorBody>) => {
    const status = err.response?.status ?? 0
    const body = err.response?.data
    const apiErr = body && typeof body === 'object' && 'code' in body
      ? new ApiError(body as ApiErrorBody, status)
      : new ApiError({ code: 0, message: err.message || 'network_error' }, status)

    const toast = useToast()

    // 401: 未登录 / 会话过期 → 跳登录
    if (status === 401) {
      const auth = useAuthStore()
      auth.clear()
      const isExpired = apiErr.code === 20002 || apiErr.code === 20001 /* CodeSessionExpired / NotLoggedIn */
      const current = router.currentRoute.value
      if (current.name !== 'login') {
        router.replace({
          name: 'login',
          query: {
            redirect: current.fullPath,
            ...(apiErr.code === 20002 ? { reason: 'session_expired' } : {}),
          },
        })
      }
      return Promise.reject(apiErr)
    }

    // 429: 限流
    if (status === 429) {
      const retryAfter = parseRetryAfter(err.response?.headers['retry-after'])
      toast.push({
        type: 'warning',
        message: i18n.global.t('common.errors.rate_limit', { seconds: retryAfter }),
        duration: Math.min(retryAfter * 1000, 10_000),
      })
      return Promise.reject(apiErr)
    }

    // 5xx: 服务异常
    if (status >= 500) {
      toast.push({
        type: 'danger',
        message: i18n.global.t('common.errors.server'),
      })
      return Promise.reject(apiErr)
    }

    // 业务 4xx:默认 toast(由调用方决定是否拦截)
    if (!apiErr.details?.suppressToast) {
      toast.push({
        type: 'danger',
        message: apiErr.message,
      })
    }

    return Promise.reject(apiErr)
  },
)

function readCookie(name: string): string | undefined {
  return document.cookie
    .split('; ')
    .find((row) => row.startsWith(name + '='))
    ?.split('=')[1]
}

function needCSRF(m?: string): boolean {
  if (!m) return false
  return !['get', 'head', 'options'].includes(m.toLowerCase())
}

function parseRetryAfter(v?: string): number {
  if (!v) return 5
  const n = parseInt(v, 10)
  return Number.isFinite(n) ? n : 5
}
```

```ts
// src/stores/auth.ts
import { defineStore } from 'pinia'
import { ref } from 'vue'
import { auth as authApi } from '@/api/auth'
import { profile as profileApi, type UserView } from '@/api/profile'

export const useAuthStore = defineStore('auth', () => {
  const user = ref<UserView | null>(null)
  const loading = ref(false)
  const ready = ref(false)  // 是否完成首次 refresh

  async function refresh() {
    loading.value = true
    try {
      user.value = await profileApi.get()
    } finally {
      loading.value = false
      ready.value = true
    }
  }

  async function passwordLogin(identity: string, password: string) {
    const resp = await authApi.login(identity, password) as { user: UserView }
    user.value = resp.user
    return resp
  }

  async function emailCodeLogin(email: string, code: string) {
    const resp = await authApi.emailLogin(email, code) as { user: UserView }
    user.value = resp.user
    return resp
  }

  async function register(payload: { username: string; email: string; password: string }) {
    const resp = await authApi.register(payload)
    if (resp.session) user.value = resp.user
    return resp
  }

  async function logout() {
    try { await authApi.logout() } catch {}
    user.value = null
  }

  function clear() { user.value = null }

  return { user, loading, ready, refresh, passwordLogin, emailCodeLogin, register, logout, clear }
})
```

App.vue 启动时**不**自动调 `refresh`(由 router guard 触发);只在 `meta.auth=true` 路由进入前 `await auth.refresh()`(若 user 为 null)。这避免登录页冗余请求。

## 8.4 useNoticeStore

```ts
// src/stores/notice.ts
import { defineStore } from 'pinia'
import { ref } from 'vue'
import { notice as noticeApi, type NoticeView } from '@/api/notice'

export const useNoticeStore = defineStore('notice', () => {
  const unreadCount = ref(0)
  const topBanner = ref<NoticeView | null>(null)
  const dismissed = ref<Set<number>>(loadDismissed())

  async function refreshUnreadCount() {
    try { unreadCount.value = await noticeApi.unreadCount() } catch {}
  }

  async function refreshTopBanner() {
    try {
      const page = await noticeApi.list({ page: 1, size: 1 })
      const top = page.items.find((n) => n.pinned && !n.is_read && !dismissed.value.has(n.id)) || null
      topBanner.value = top
    } catch {}
  }

  function markRead(id: number) {
    if (unreadCount.value > 0) unreadCount.value--
    if (topBanner.value?.id === id) topBanner.value = null
  }

  function dismissBanner(id: number) {
    dismissed.value.add(id)
    localStorage.setItem('proapi.notice.dismissed', JSON.stringify([...dismissed.value]))
    topBanner.value = null
  }

  return { unreadCount, topBanner, refreshUnreadCount, refreshTopBanner, markRead, dismissBanner }
})

function loadDismissed(): Set<number> {
  try {
    const raw = localStorage.getItem('proapi.notice.dismissed')
    return new Set(raw ? JSON.parse(raw) : [])
  } catch { return new Set() }
}
```

```ts
import { i18n } from '@/i18n'

export function messageFromApiError(err: { code: number; message?: string }): string {
```
