# 里程碑 M1-09 admin 后台前端

## 1. 目标范围

### 1.1 一句话

把 M1 后端 11 个模块(用户/令牌/适配器/渠道/计费/限流/日志/公告/设置/充值审批/兑换码)的所有 admin HTTP endpoint **聚成一个完整的 Vue 3 + TypeScript + Naive UI + UnoCSS 后台应用**,覆盖登录、仪表盘、用户管理、渠道管理、模型与定价、日志统计、公告与系统设置、手动充值审批、兑换码批量生成等核心页面,部署到 `/admin/` 路径。

### 1.2 范围

属于本 spec 的(11 件事):

1. 完整路由表(约 25 条):path / name / meta(roles / title / breadcrumb)/ component / 守卫
2. 两套布局:`AppLayout`(SessionAuth 后)+ `AuthLayout`(登录页)+ 暗色模式 ConfigProvider
3. 18-22 个页面的设计稿(草图 / 组件树 / 字段 / 交互流程 / 调 API / 错误处理 / 暗色适配 / i18n key)
4. 共享 API 调用层 `src/api/`:17 个文件(http.ts 含拦截器 + 16 个领域 api)
5. Pinia stores:`useUserStore` / `useAppStore` / `useDictStore`
6. 共享业务组件 `src/components/`:`<ListPage>` / `<FilterDrawer>` / `<FormDrawer>` / `<ConfirmDialog>` / `<CopyButton>` / `<MoneyDisplay>` / `<TimeDisplay>` / `<KeyDisplay>` / `<ChartLine>` / `<ChartBar>` / `<ChartPie>`
7. i18n 结构:复用 `web/shared/src/i18n/{zh,en}.json` 顶层 key + admin 专属 `web/admin/src/i18n/{zh,en}.json` 按页面命名空间
8. 路由权限策略:`meta.roles` 数组 + `beforeEach` 全局守卫
9. 测试用例:Vitest 单元 + Vitest 组件 + Playwright E2E 6 条主链路
10. 实施任务:5 个 phase(布局 → 工具组件 → API 层 → 各页面分批 → E2E)
11. 与后端契约的对齐(URL/method/字段/错误码)— 不重写后端契约,只锚点引用

### 1.3 排除项(明确边界)

- ❌ **M2 起的功能入口**:Anthropic / Gemini 入口管理、Playground / 模型广场、邀请管理、Stripe / 支付宝 / 微信支付配置、Google / 飞书 / 微信 / 钉钉 OAuth 配置;系统设置页仅渲染 M1-12 §6 定义的 30+ 已 seed 的 key
- ❌ **M3 起的功能**:SSO / 部门 / 完整审计页(本 spec 仅做"日志/审计"的只读列表,不做"部门审计"等),M3 的 placeholder 链接放在侧边栏底部 "Coming in M3"
- ❌ **DALL-E / TTS / STT / MJ / Suno UI**(M2)
- ❌ **真实的 ECharts 截图 / 像素级 mockup**:本 spec 只给 ASCII 草图 + 字段 + 数据源,实际渲染细节交给实现
- ❌ **后端实现细节**:本 spec 不涉及任何 Go 代码;HTTP API 的具体响应字段以各后端 spec 为准,本 spec 只列 path / method / 入参 / 关键响应字段
- ❌ **用户前台**:见 [M1-10](./2026-05-21-里程碑1-10-user前台-设计稿.md)

### 2.3 guard.ts(全局守卫)

```ts
// router/guard.ts
import type { Router } from 'vue-router'
import { useUserStore } from '@/stores/user'

export function installGuards(router: Router) {
  router.beforeEach(async (to) => {
    const us = useUserStore()
    // 1. 公开路由直接放行
    if (to.name === 'login' || to.name === 'forbidden' || to.name === 'not-found') return true
    // 2. 未拉过 me → 拉取一次
    if (!us.fetched) {
      try { await us.fetchMe() } catch (_) { /* 401 由 http 拦截器处理跳 /login */ }
    }
    // 3. 未登录 → 跳 /login(http 拦截器已处理,这里兜底)
    if (!us.user) {
      return { name: 'login', query: { redirect: to.fullPath } }
    }
    // 4. role 不在 meta.roles 中 → 跳 /403(meta.roles 空数组 = 仅需登录)
    const roles = (to.meta?.roles as number[] | undefined) ?? []
    if (roles.length > 0 && !roles.includes(us.user.role)) {
      return { name: 'forbidden' }
    }
    return true
  })

  // 标题
  router.afterEach((to) => {
    const t = (to.meta?.title as string | undefined) ?? 'app.name'
    // 由各页面 setup() 调 useHead/useTitle 设置;路由仅给 fallback
    if (typeof document !== 'undefined') {
      document.title = `${t} · proapi admin`
    }
  })
}
```

- **调用 API**:
  - `POST /api/admin/auth/login` (M1-02 §5.3.1)
  - `GET /api/auth/oauth/github/start?redirect=/admin/` 重定向(M1-02 §5.1.8)
- **错误 / 空状态 / loading**:按钮 `loading` 期间禁用所有输入;错误用 NMessage 提示 + 红字提示
- **暗色适配**:NCard / NInput / NButton 全部走 NaiveUI 主题变量,无额外工作
- **i18n keys**:`login.title / login.subtitle / login.identity / login.password / login.submit / login.github / login.errors.wrong_password / login.errors.not_admin / login.errors.email_not_verified / login.errors.captcha_invalid`

```ts
// api/http.ts
import axios, { type AxiosInstance, type AxiosError, type AxiosRequestConfig } from 'axios'
import qs from 'qs'
import { useMessage, useLoadingBar } from 'naive-ui'  // 仅类型;实际通过 i18n.ts 的全局注入
import i18n from '@/i18n'
import { useUserStore } from '@/stores/user'
import { router } from '@/router'

// 注入式持有 NaiveUI Provider 暴露的实例(在 App.vue 挂载完成后注入)
// 通过 src/utils/discrete.ts 用 createDiscreteApi 也可;此处直接用 window 全局兜底
declare global {
  interface Window {
    $message?: ReturnType<typeof useMessage>
    $loadingBar?: ReturnType<typeof useLoadingBar>
  }
}

const csrfTokenFromCookie = () =>
  document.cookie
    .split('; ')
    .find((c) => c.startsWith('proapi_csrf='))
    ?.split('=')[1] ?? ''

const isUnsafeMethod = (m?: string) =>
  ['post', 'put', 'patch', 'delete'].includes((m || 'get').toLowerCase())

export const http: AxiosInstance = axios.create({
  baseURL: '/',
  timeout: 30_000,
  withCredentials: true,
  paramsSerializer: { serialize: (p) => qs.stringify(p, { arrayFormat: 'brackets', skipNulls: true }) },
})

http.interceptors.request.use((cfg) => {
  // CSRF 注入
  if (isUnsafeMethod(cfg.method)) {
    const t = csrfTokenFromCookie()
    if (t) cfg.headers.set('X-CSRF-Token', t)
  }
  // 语言
  cfg.headers.set('Accept-Language', (i18n.global.locale as any).value || 'zh')
  // loading bar
  window.$loadingBar?.start()
  return cfg
})

http.interceptors.response.use(
  (resp) => {
    window.$loadingBar?.finish()
    return resp
  },
  (err: AxiosError<{ code: number; message: string; details?: any }>) => {
    window.$loadingBar?.error()
    const status = err.response?.status
    const code = err.response?.data?.code
    const message = err.response?.data?.message || err.message
    const t = (k: string, fallback?: string) => (i18n.global.t(k) === k ? fallback || k : i18n.global.t(k))

    // 401 - 未登录 / session 过期
    if (status === 401) {
      const us = useUserStore()
      us.clear()
      if (router.currentRoute.value.name !== 'login') {
        const redirect = router.currentRoute.value.fullPath
        router.push({ name: 'login', query: { redirect, reason: code === 20002 ? 'session_expired' : undefined } })
      }
      return Promise.reject(err)
    }
    // 403 - 权限不足
    if (status === 403) {
      window.$message?.error(message || t('errors.forbidden', '权限不足'))
      return Promise.reject(err)
    }
    // 429 - 限流(读 Retry-After)
    if (status === 429) {
      const retry = err.response?.headers?.['retry-after']
      window.$message?.warning(
        retry
          ? t('errors.rate_limited_with_retry', '请求过快,{seconds}s 后再试').replace('{seconds}', String(retry))
          : message || t('errors.rate_limited', '请求过快,请稍后再试')
      )
      return Promise.reject(err)
    }
    // 5xx
    if (status && status >= 500) {
      window.$message?.error(t('errors.server', '服务器错误,请稍后重试'))
      return Promise.reject(err)
    }
    // 其他 4xx
    window.$message?.error(message || t('errors.unknown', '未知错误'))
    return Promise.reject(err)
  }
)

// 通用类型
export type Page<T> = { items: T[]; total: number; page: number; size: number }
export type Ok = { ok: true }

// 包装:返回 res.data,屏蔽 axios response 壳
export async function get<T>(url: string, params?: Record<string, any>, cfg?: AxiosRequestConfig) {
  return http.get<T>(url, { params, ...cfg }).then((r) => r.data)
}
export async function post<T>(url: string, body?: any, cfg?: AxiosRequestConfig) {
  return http.post<T>(url, body, cfg).then((r) => r.data)
}
export async function patch<T>(url: string, body?: any, cfg?: AxiosRequestConfig) {
  return http.patch<T>(url, body, cfg).then((r) => r.data)
}
export async function del<T>(url: string, params?: Record<string, any>, cfg?: AxiosRequestConfig) {
  return http.delete<T>(url, { params, ...cfg }).then((r) => r.data)
}
```

```ts
// stores/user.ts
import { defineStore } from 'pinia'
import { authApi, type AdminUser } from '@/api/auth'

interface State {
  user: AdminUser | null
  fetched: boolean
  fetching: boolean
}

export const useUserStore = defineStore('user', {
  state: (): State => ({ user: null, fetched: false, fetching: false }),
  getters: {
    isLoggedIn: (s) => !!s.user,
    role: (s) => s.user?.role ?? 0,
    isSuperAdmin: (s) => s.user?.role === 3,
  },
  actions: {
    async fetchMe() {
      if (this.fetching) return
      this.fetching = true
      try {
        const u = await authApi.me()
        this.user = u
      } catch (e) {
        this.user = null
        throw e
      } finally {
        this.fetched = true
        this.fetching = false
      }
    },
    async login(identity: string, password: string) {
      const r = await authApi.login({ identity, password })
      this.user = r.user
      this.fetched = true
    },
    async logout() {
      try { await authApi.logout() } catch (_) { /* 即使失败也清本地 */ }
      this.clear()
    },
    clear() {
      this.user = null
      this.fetched = true
    },
    /** 权限检查:仅供 UI 控制 disable;真正权限在路由守卫 + 后端 */
    hasRole(min: 0 | 1 | 2 | 3) { return (this.user?.role ?? 0) >= min }
  },
})
```

### 6.2 `useAppStore`

```ts
// stores/app.ts
import { defineStore } from 'pinia'

type Theme = 'light' | 'dark' | 'system'
type Locale = 'zh' | 'en'

interface State {
  theme: Theme
  resolvedTheme: 'light' | 'dark'   // 实际生效(system → 系统媒体查询)
  locale: Locale
  sidebarCollapsed: boolean
  tabs: Array<{ name: string; path: string; title: string }>  // 顶部 tab 历史(可选)
}

const KS = {
  theme: 'proapi_admin_theme',
  locale: 'proapi.locale',
  collapsed: 'proapi_admin_sidebar_collapsed',
}

function resolveTheme(t: Theme): 'light' | 'dark' {
  if (t === 'system') return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light'
  return t
}

export const useAppStore = defineStore('app', {
  state: (): State => ({
    theme: (localStorage.getItem(KS.theme) as Theme) || 'system',
    resolvedTheme: 'light',
    locale: (localStorage.getItem(KS.locale) as Locale) || 'zh',
    sidebarCollapsed: localStorage.getItem(KS.collapsed) === '1',
    tabs: [],
  }),
  actions: {
    init() {
      this.resolvedTheme = resolveTheme(this.theme)
      this.applyTheme()
      window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', () => {
        if (this.theme === 'system') { this.resolvedTheme = resolveTheme('system'); this.applyTheme() }
      })
    },
    setTheme(t: Theme) {
      this.theme = t
      localStorage.setItem(KS.theme, t)
      this.resolvedTheme = resolveTheme(t)
      this.applyTheme()
    },
    applyTheme() {
      document.documentElement.classList.toggle('dark', this.resolvedTheme === 'dark')
    },
    setLocale(l: Locale) {
      this.locale = l
      localStorage.setItem(KS.locale, l)
      // 通过 i18n 实例切换在 component 处理(stores 不直接 import i18n 避免循环)
    },
    toggleSidebar() {
      this.sidebarCollapsed = !this.sidebarCollapsed
      localStorage.setItem(KS.collapsed, this.sidebarCollapsed ? '1' : '0')
    },
    pushTab(t: State['tabs'][number]) {
      if (!this.tabs.find((x) => x.name === t.name)) this.tabs.push(t)
    },
    closeTab(name: string) {
      this.tabs = this.tabs.filter((x) => x.name !== name)
    },
  },
})
```

### 6.3 `useDictStore`

```ts
// stores/dict.ts
import { defineStore } from 'pinia'
import { modelApi, type ModelCatalog } from '@/api/model'
import { channelApi, type Channel } from '@/api/channel'
import { groupApi, type Group } from '@/api/group'

interface CachedList<T> { data: T[]; fetchedAt: number; loading: boolean; promise: Promise<void> | null }
const empty = <T>(): CachedList<T> => ({ data: [], fetchedAt: 0, loading: false, promise: null })

const TTL = 5 * 60 * 1000

export const useDictStore = defineStore('dict', {
  state: () => ({
    models: empty<ModelCatalog>(),
    channels: empty<Channel>(),
    groups: empty<Group>(),
  }),
  getters: {
    modelOptions: (s) => s.models.data.map((m) => ({ label: m.name, value: m.name })),
    groupOptions: (s) => s.groups.data.map((g) => ({ label: g.display_name || g.name, value: g.id })),
    channelOptions: (s) => s.channels.data.map((c) => ({ label: c.name, value: c.id })),
  },
  actions: {
    async ensureModels() { await this.ensure('models', async () => (await modelApi.list({ page: 1, size: 1000 })).items) },
    async ensureChannels() { await this.ensure('channels', async () => (await channelApi.list({ page: 1, size: 1000 })).items) },
    async ensureGroups() { await this.ensure('groups', async () => (await groupApi.list()).items) },
    async refreshAll() {
      this.models.fetchedAt = 0; this.channels.fetchedAt = 0; this.groups.fetchedAt = 0
      await Promise.all([this.ensureModels(), this.ensureChannels(), this.ensureGroups()])
    },
    async ensure<K extends 'models' | 'channels' | 'groups'>(key: K, fetcher: () => Promise<any[]>) {
      const c: CachedList<any> = (this as any)[key]
      const now = Date.now()
      if (now - c.fetchedAt < TTL && c.data.length) return
      if (c.promise) { await c.promise; return }
      c.loading = true
      c.promise = (async () => {
        try { c.data = await fetcher(); c.fetchedAt = now }
        finally { c.loading = false; c.promise = null }
      })()
      await c.promise
    },
  },
})
```

## 9. 路由权限

### 9.1 `meta.roles` 语义

- 类型:`number[]`(每项 ∈ `0/1/2/3`)
- 空数组 `[]`:仅要求"已登录"(profile / 403 / 404 / login 自身);为完全公开 + 自带逻辑判断
- `[3]`:**仅超级管理员**(M1 的标准要求 — 后台几乎所有页)
- `[2, 3]`:租户管理员 + 超级管理员;M1 适用页面:`/profile`(allow 自查 role>=2)
- `[1, 2, 3]`:含部门管理员;**M1 不使用**,**为 M3 部门后台预留**

### 9.2 守卫策略

见 §2.3 `guard.ts`。要点:

1. 公开路由直接放行
2. 未拉 `me` → 先调 `userStore.fetchMe()`;失败由 http 拦截器跳 `/login`
3. 已登录但 role 不在 `meta.roles` → 跳 `/403`
4. 通过 → 放行

### 9.3 UI 级别二次校验

- 侧边栏菜单:`menu.ts` 根据 `user.role` 与 `route.meta.roles` 过滤显示;**M3 占位项**显示但 `disabled` + Tooltip "M3 起开放"
- 按钮:用 `v-if="userStore.hasRole(3)"` 在 vue 里隐藏(虽然路由已守卫,UI 仍二次校验防止误触)

### 9.4 与后端的对齐

后端 `/api/admin/*` 默认 `RoleGate(RoleTenantAdmin)` 即 `role>=2`(M1-02 §5.3);本前端 M1 把绝大部分页面限制更严为 `[3]`,理由:

- M1 仅有"超管"一种实际管理员(M0 部署 seed 只建一个 super)
- `role=2` 的"租户管理员"在 M1 几乎没有专属能力,实质用例为 M2 多租户引入后才有意义
- 前端先严后宽:若 M2 引入 tenant 后台,只需把 `meta.roles` 从 `[3]` 改 `[2, 3]` 即可

`/profile` 例外:允许 role >= 2,因为该页只看自己。

### 9.5 强制下线(401 拦截)

M1-02 已实现 RevokeAllForUser → 用户下次任何请求 401:

1. http.ts 401 拦截器 → `userStore.clear()` → push `/login?reason=session_expired&redirect=<from>`
2. 登录页读 query `reason`:渲染顶部红色 alert "登录已失效,请重新登录"

- 暗色与浅色模式下所有页面均无对比度问题(WCAG AA 通过)
- 中英文文案不溢出(关键卡片预留)

### 13.4 与后端的契约对齐

- 后端任一路由响应 `{code, message, details}` 时,前端 message 显示中文(默认 `Accept-Language: zh`)
- CSRF 双 cookie 流程:登录后种 `proapi_session`(HttpOnly)+ `proapi_csrf`(非 HttpOnly);所有 unsafe 请求自动带 `X-CSRF-Token`
- 401 拦截后跳 `/login?reason=session_expired&redirect=<from>`,登录页读 query 显示 alert
- 强制下线(管理员禁用某用户)→ 该用户后台浏览器下次请求 401 自动跳 /login
