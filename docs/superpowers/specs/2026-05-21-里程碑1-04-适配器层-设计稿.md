# 里程碑 M1-04 适配器层

## 1. 目标与范围

### 1.1 一句话

**在 OpenAI 入口编解码 + 中间表示(IR)+ 9 家上游适配器之间架起统一桥** — 把入口的 OpenAI HTTP 请求解码为 IR,通过 `adapter.Adapter` 接口调到对应上游,把上游响应回编为 OpenAI JSON / SSE 返回客户端。

本 spec **不**承担"渠道选择 / 重试 / 熔断"(M1-05)、"计费"(M1-06)、"限流"(M1-07)、"日志写入"(M1-08)— 这些由 relay 编排层在调用 adapter 前/后完成。本 spec 提供 relay 调用 adapter 的**最简骨架**:`relay.CallChat(ctx, ch, irReq) → (*ir.ChatResponse, error)`,后续 M1-05 加渠道选择 + retry 包装。

### 1.2 范围

属于本 spec 的(12 件事):

1. **IR(`internal/protocol/ir/`)**:[总纲 §4.2](./2026-05-21-里程碑1-总体设计纲要.md#42-irintermediate-representation) 数据结构的 Go 实现 + `Validate(*ChatRequest)` / `Validate(*EmbedRequest)` 等验证函数
2. **OpenAI 入口编解码(`internal/protocol/openai/`)**:
   - request decode:HTTP body → `ir.ChatRequest / ir.EmbedRequest / ir.CompletionRequest`
   - response encode:IR → OpenAI JSON
   - SSE stream encode:`ir.ChatChunk` → `data: {...}\n\n` + 流末 `data: [DONE]\n\n`
3. **适配器接口与注册(`internal/adapter/`)**:实现 [总纲 §4.1](./2026-05-21-里程碑1-总体设计纲要.md#41-adapter) 的 `Adapter / Registry / Capability / Credential`,显式 `adapter.RegisterAll(app)` 在 wire 阶段调用 9 家 `init`
4. **9 家适配器**(每家一个子包 `internal/adapter/<provider>/`):
   - `openai` — OpenAI 原生(chat + stream + embed)
   - `azure` — Azure OpenAI(deployment 映射存 `channel.extra`)
   - `anthropic` — Claude Messages API(IR 与 Anthropic 双向翻译,system / tool_use / tool_result)
   - `gemini` — Gemini `generateContent`(IR 双向翻译,`contents[].parts[]`)
   - `deepseek` — OpenAI 兼容(极简)
   - `moonshot` — OpenAI 兼容
   - `zhipu` — GLM 4 API(auth 头是 JWT 签名,给出签名实现)
   - `qwen` — 阿里通义(OpenAI 兼容 + 私有扩展)
   - `doubao` — 字节豆包(火山引擎,API 路径与 OpenAI 略不同)
5. **`model_catalogs` 表 + migration** `000008_create_model_catalogs.{up,down}.sql`([总纲 §2.7](./2026-05-21-里程碑1-总体设计纲要.md#27--model_catalogs))
6. **模型字典 seed**(M1-04 提供 25-40 个常见模型)+ migration `000023_seed_model_catalogs.{up,down}.sql`
7. **HTTP handler**(代理入口,被 [M1-03 TokenAuth](./2026-05-21-里程碑1-03-API令牌-设计稿.md#35-tokenauth-中间件) 保护):
   - `POST /v1/chat/completions`(非流 + 流式)
   - `POST /v1/completions`(legacy,内部转 chat completions)
   - `POST /v1/embeddings`
   - `GET /v1/models`(由 M1-03 提供,本 spec 仅提供 `ModelInfo` 数据来源)
8. **relay 编排骨架** `internal/relay/`:本 spec 只提供"调单家 adapter"调用 — 渠道选择 / retry / 计费在 M1-05/06 注入
9. **tokenizer 注册**:每个 adapter 在 `init` 把 `gpt-*` / `claude-*` / 等 pattern 注册到 `tokenize.Registry`(M1-01 提供)
10. **`channel.extra` 用法约定**:Azure deployment 映射 `{"deployments": {"gpt-4": "my-deployment-name"}}`,各 provider 私有扩展
11. **错误归类规则**:adapter 内部识别上游 `429` / `5xx` / `timeout` / `quota_exceeded` / `content_filter` → 映射到 `apierr.Code*`
12. **HTTP client 工厂**:每家 adapter 自带 `http.Client{Timeout: 默认 60s}`,可被 setting `adapter.<provider>.timeout_seconds` override

### 1.3 排除项(明确边界)

- ❌ 渠道选择 / 重试 / 熔断(M1-05) — 本 spec 的 relay 骨架只调单家
- ❌ 计费(M1-06) — adapter 不参与;但 adapter 在 ChatStream 末尾把 usage 透出 IR(若上游给)
- ❌ 限流(M1-07) — middleware 链已在 TokenAuth 后注入,与 adapter 解耦
- ❌ 日志写入(M1-08) — adapter 不写日志,只通过 zap.Debug 打 trace
- ❌ 多模态(image / audio / rerank / MJ / Suno) — 推 M2
- ❌ Anthropic / Gemini 入口协议 — 入口仍是 OpenAI 格式,Anthropic / Gemini 仅作 backend adapter
- ❌ `model_aliases` 表的运行时逻辑 — 决策:**推 M2**,本 spec 不建该表(回写 [总纲 §2.20](./2026-05-21-里程碑1-总体设计纲要.md#220--model_aliases可选m1-可选实现) 标"M2 实现")
- ❌ `function calling` 的细化语义(parallel tool calls / strict mode)— M1 通用支持;不区分 OpenAI 新旧字段细节

#### 3.1.2 验证函数

```go
// internal/protocol/ir/validate.go
package ir

import (
    "github.com/proapi/proapi/pkg/apierr"
)

// Validate 校验 ChatRequest 的最低必备字段。
//   - model 不可空 → CodeMissingParam
//   - messages 至少 1 条 → CodeMissingParam
//   - 每条 message role 必须为合法枚举 → CodeInvalidParam
//   - tool message 必须有 tool_call_id → CodeInvalidParam
//   - tool_call assistant message 内 ToolCalls 必须有 ID
//   - max_tokens < 0 → CodeInvalidParam
//   - temperature ∉ [0, 2] → CodeInvalidParam
//   - top_p ∉ [0, 1] → CodeInvalidParam
//   - stop 最多 4 条
func Validate(r *ChatRequest) error {
    if r == nil { return apierr.New(apierr.CodeMissingParam, "request is nil") }
    if r.Model == "" { return apierr.New(apierr.CodeMissingParam, "model is required") }
    if len(r.Messages) == 0 {
        return apierr.New(apierr.CodeMissingParam, "messages must not be empty")
    }
    for i, m := range r.Messages {
        switch m.Role {
        case RoleSystem, RoleUser, RoleAssistant, RoleTool:
        default:
            return apierr.New(apierr.CodeInvalidParam,
                fmt.Sprintf("messages[%d].role invalid: %s", i, m.Role))
        }
        if m.Role == RoleTool && m.ToolCallID == "" {
            return apierr.New(apierr.CodeInvalidParam,
                fmt.Sprintf("messages[%d] tool message requires tool_call_id", i))
        }
        if m.Role == RoleAssistant {
            for j, tc := range m.ToolCalls {
                if tc.ID == "" || tc.Function.Name == "" {
                    return apierr.New(apierr.CodeInvalidParam,
                        fmt.Sprintf("messages[%d].tool_calls[%d] missing id/name", i, j))
                }
            }
        }
        for j, p := range m.Content {
            if p.Type == "" {
                return apierr.New(apierr.CodeInvalidParam,
                    fmt.Sprintf("messages[%d].content[%d].type empty", i, j))
            }
        }
    }
    if r.MaxTokens < 0 {
        return apierr.New(apierr.CodeInvalidParam, "max_tokens must be >= 0")
    }
    if r.Temperature != nil && (*r.Temperature < 0 || *r.Temperature > 2) {
        return apierr.New(apierr.CodeInvalidParam, "temperature must be in [0,2]")
    }
    if r.TopP != nil && (*r.TopP < 0 || *r.TopP > 1) {
        return apierr.New(apierr.CodeInvalidParam, "top_p must be in [0,1]")
    }
    if len(r.Stop) > 4 {
        return apierr.New(apierr.CodeInvalidParam, "at most 4 stop sequences")
    }
    return nil
}

func ValidateEmbed(r *EmbedRequest) error {
    if r == nil { return apierr.New(apierr.CodeMissingParam, "request is nil") }
    if r.Model == "" { return apierr.New(apierr.CodeMissingParam, "model is required") }
    if len(r.Input) == 0 {
        return apierr.New(apierr.CodeMissingParam, "input must not be empty")
    }
    for i, s := range r.Input {
        if s == "" {
            return apierr.New(apierr.CodeInvalidParam,
                fmt.Sprintf("input[%d] must not be empty", i))
        }
    }
```

### 3.3 Registry

```go
// internal/adapter/registry.go
package adapter

import (
    "fmt"
    "sync"
)

type Registry interface {
    Register(a Adapter)
    Get(name string) (Adapter, bool)
    List() []Adapter
    MustGet(name string) Adapter
}

type registry struct {
    mu sync.RWMutex
    m  map[string]Adapter
}

func NewRegistry() Registry { return &registry{m: map[string]Adapter{}} }

func (r *registry) Register(a Adapter) {
    r.mu.Lock()
    defer r.mu.Unlock()
    if _, exists := r.m[a.Name()]; exists {
        panic(fmt.Sprintf("adapter %s already registered", a.Name()))
    }
    r.m[a.Name()] = a
}

func (r *registry) Get(name string) (Adapter, bool) {
    r.mu.RLock()
    defer r.mu.RUnlock()
    a, ok := r.m[name]
    return a, ok
}

func (r *registry) MustGet(name string) Adapter {
    a, ok := r.Get(name)
    if !ok { panic("unknown adapter: " + name) }
    return a
}

func (r *registry) List() []Adapter {
    r.mu.RLock()
    defer r.mu.RUnlock()
    out := make([]Adapter, 0, len(r.m))
    for _, a := range r.m { out = append(out, a) }
    return out
}
```

```go
    return &http.Client{
```

### 3.5 错误归类 helper

```go
// internal/adapter/error.go
package adapter

import (
    "context"
    "errors"
    "net"
    "net/http"
    "syscall"

    "github.com/proapi/proapi/pkg/apierr"
)

// ClassifyHTTPStatus 根据上游响应 status code + body 类型生成 *apierr.Error。
//   - 429              → CodeUpstreamRateLimit
//   - 401 / 403        → CodeChannelMisconfig(凭证问题,不是用户问题)
//   - 402              → CodeUpstreamQuota
//   - 5xx              → CodeUpstreamError
//   - 503              → CodeUpstreamUnavail
//   - 400              → CodeInvalidParam(透传上游错误 body 给客户端,help debug)
//   - 其他             → CodeUpstreamError
//   - body 含 "content_filter" / "content_policy" → CodeUpstreamContentFilter
func ClassifyHTTPStatus(status int, body []byte) *apierr.Error {
    bodyStr := string(body)
    if containsContentFilterMarker(bodyStr) {
        return apierr.New(apierr.CodeUpstreamContentFilter, "upstream content filter triggered").
            WithDetails(truncate(bodyStr, 512))
    }
    switch {
    case status == 429:
        return apierr.New(apierr.CodeUpstreamRateLimit, "upstream rate limited").
            WithDetails(truncate(bodyStr, 512))
    case status == 401 || status == 403:
        return apierr.New(apierr.CodeChannelMisconfig, "upstream auth failed").
            WithDetails(truncate(bodyStr, 256))  // 不暴露给客户端,只内部 log
    case status == 402:
        return apierr.New(apierr.CodeUpstreamQuota, "upstream quota exhausted").
            WithDetails(truncate(bodyStr, 256))
    case status == 503:
        return apierr.New(apierr.CodeUpstreamUnavail, "upstream unavailable").
            WithDetails(truncate(bodyStr, 256))
    case status >= 500:
        return apierr.New(apierr.CodeUpstreamError, fmt.Sprintf("upstream returned %d", status)).
            WithDetails(truncate(bodyStr, 512))
    case status == 400:
        return apierr.New(apierr.CodeInvalidParam, "upstream rejected request").
            WithDetails(truncate(bodyStr, 512))
    default:
        return apierr.New(apierr.CodeUpstreamError, fmt.Sprintf("unexpected status %d", status)).
            WithDetails(truncate(bodyStr, 256))
    }
}

// ClassifyNetErr 把网络/IO 错误归类。
//   - ctx canceled / deadline → CodeUpstreamTimeout
//   - net.OpError + connection refused → CodeUpstreamUnavail
//   - 其他网络错 → CodeUpstreamError
func ClassifyNetErr(err error) *apierr.Error {
    if err == nil { return nil }
    if errors.Is(err, context.Canceled) {
        return apierr.New(apierr.CodeUpstreamTimeout, "request canceled")
    }
    if errors.Is(err, context.DeadlineExceeded) {
        return apierr.New(apierr.CodeUpstreamTimeout, "request timeout")
    }
    var nerr net.Error
    if errors.As(err, &nerr) && nerr.Timeout() {
        return apierr.New(apierr.CodeUpstreamTimeout, "network timeout")
    }
    if errors.Is(err, syscall.ECONNREFUSED) {
        return apierr.New(apierr.CodeUpstreamUnavail, "connection refused")
    }
    return apierr.New(apierr.CodeUpstreamError, err.Error())
}

func containsContentFilterMarker(s string) bool {
    s = strings.ToLower(s)
    return strings.Contains(s, "content_filter") ||
        strings.Contains(s, "content_policy") ||
        strings.Contains(s, "responsibleaipolicy")
}

func truncate(s string, n int) string {
    if len(s) <= n { return s }
    return s[:n] + "..."
}
```

```go
// internal/adapter/sse.go
package adapter

import (
    "bufio"
    "errors"
    "io"
    "strings"
)

// SSEReader 按 SSE 协议从 stream 中按 event 块读取。
// 一个 event 块以一个空行结束;每行内部 "field: value"。
type SSEReader struct {
    br *bufio.Reader
}

func NewSSEReader(r io.Reader) *SSEReader {
    return &SSEReader{br: bufio.NewReaderSize(r, 64*1024)}
}

// Event 是单个 SSE 事件。
type Event struct {
    Event string
    Data  string  // 多行 data 用 \n 连接
    ID    string
}

// Next 读取下一个 event;io.EOF 表示流结束。
func (r *SSEReader) Next() (*Event, error) {
    e := &Event{}
    has := false
    for {
        line, err := r.br.ReadString('\n')
        if err != nil {
            if errors.Is(err, io.EOF) && has {
                return e, nil
            }
            return nil, err
        }
        line = strings.TrimRight(line, "\r\n")
        if line == "" {
            if has { return e, nil }
            continue  // 多个空行
        }
        if strings.HasPrefix(line, ":") {
            continue  // 注释
        }
        if i := strings.IndexByte(line, ':'); i >= 0 {
            field := line[:i]
            val := strings.TrimPrefix(line[i+1:], " ")
            switch field {
            case "data":
                if e.Data != "" {
                    e.Data += "\n" + val
                } else {
                    e.Data = val
                }
                has = true
            case "event":
                e.Event = val
                has = true
            case "id":
                e.ID = val
                has = true
            }
        }
    }
}
```

```go
// internal/protocol/openai/decode.go
package openai

import (
    "encoding/json"
    "io"

    "github.com/proapi/proapi/internal/protocol/ir"
    "github.com/proapi/proapi/pkg/apierr"
)

// DecodeChat 把 HTTP body → ir.ChatRequest。
func DecodeChat(r io.Reader) (*ir.ChatRequest, error) {
    var dto ChatRequestDTO
    dec := json.NewDecoder(r)
    dec.DisallowUnknownFields()  // M1 严格:多余字段拒绝,引导客户端修正
    // 但保留一个口子:发起方在 ExtraParams 透传 → 见下
    if err := dec.Decode(&dto); err != nil {
        return nil, apierr.New(apierr.CodeInvalidParam, "invalid JSON: "+err.Error())
    }
    req := &ir.ChatRequest{
        Model:       dto.Model,
        Temperature: dto.Temperature,
        TopP:        dto.TopP,
        Stream:      dto.Stream,
        User:        dto.User,
        Seed:        dto.Seed,
        ExtraParams: map[string]any{},
    }
    // max_tokens / max_completion_tokens 统一存 MaxTokens
    if dto.MaxCompletionTokens != nil {
        req.MaxTokens = *dto.MaxCompletionTokens
    } else if dto.MaxTokens != nil {
        req.MaxTokens = *dto.MaxTokens
    }
    // stop: string 或 []string
    if len(dto.Stop) > 0 {
        var s string
        if err := json.Unmarshal(dto.Stop, &s); err == nil {
            req.Stop = []string{s}
        } else {
            _ = json.Unmarshal(dto.Stop, &req.Stop)
        }
    }
    // messages
    for _, mDTO := range dto.Messages {
        m := ir.Message{
            Role:       mDTO.Role,
            Name:       mDTO.Name,
            ToolCallID: mDTO.ToolCallID,
        }
        // content: 字符串 → 单 text part;数组 → 多 parts
        if len(mDTO.Content) > 0 {
            var s string
            if err := json.Unmarshal(mDTO.Content, &s); err == nil {
                m.Content = []ir.ContentPart{{Type: ir.ContentText, Text: s}}
            } else {
                var parts []ContentPartDTO
                if err := json.Unmarshal(mDTO.Content, &parts); err != nil {
                    return nil, apierr.New(apierr.CodeInvalidParam,
                        "messages.content must be string or array")
                }
                for _, p := range parts {
                    cp := ir.ContentPart{Type: p.Type, Text: p.Text}
                    if p.ImageURL != nil {
                        cp.ImageURL = ir.ImageURL{URL: p.ImageURL.URL, Detail: p.ImageURL.Detail}
                    }
                    m.Content = append(m.Content, cp)
                }
            }
        }
        for _, tc := range mDTO.ToolCalls {
            m.ToolCalls = append(m.ToolCalls, ir.ToolCall{
                ID: tc.ID, Type: tc.Type,
                Function: ir.ToolCallFunction{Name: tc.Function.Name, Arguments: tc.Function.Arguments},
            })
        }
        req.Messages = append(req.Messages, m)
    }
    // tools
    for _, t := range dto.Tools {
        req.Tools = append(req.Tools, ir.Tool{
            Type: t.Type,
            Function: ir.FunctionTool{
                Name: t.Function.Name, Description: t.Function.Description,
                Parameters: t.Function.Parameters,
            },
        })
    }
    if len(dto.ToolChoice) > 0 {
        var any any
        _ = json.Unmarshal(dto.ToolChoice, &any)
        req.ToolChoice = any
    }
    if dto.ResponseFormat != nil {
        req.ResponseFormat = &ir.ResponseFormat{
            Type:   dto.ResponseFormat.Type,
            Schema: dto.ResponseFormat.JSONSchema,
        }
    }
    return req, nil
}
```

```go
type StreamWriter struct {
    w     io.Writer
    flush func()
}

func NewStreamWriter(w io.Writer, flush func()) *StreamWriter {
    return &StreamWriter{w: w, flush: flush}

func (s *StreamWriter) WriteChunk(chunk *ir.ChatChunk) error {
    dto := ChatChunkDTO{
        ID: chunk.ID, Object: "chat.completion.chunk", Created: time.Now().Unix(),
        Model: chunk.Model,
        Choices: []ChoiceChunkDTO{{
            Index: 0, FinishReason: chunk.FinishReason,
            Delta: DeltaDTO{
                Role: chunk.Delta.Role, Content: chunk.Delta.Content,
            },
        }},
    }
    for _, tc := range chunk.Delta.ToolCalls {
        dto.Choices[0].Delta.ToolCalls = append(dto.Choices[0].Delta.ToolCalls, ToolCallDTO{
            Index: tc.Index, ID: tc.ID, Type: "function",
            Function: FunctionCallDTO{Name: tc.Function.Name, Arguments: tc.Function.Arguments},
        })
    }
    if chunk.Usage != nil {
        dto.Usage = &UsageDTO{
            PromptTokens: chunk.Usage.PromptTokens,
            CompletionTokens: chunk.Usage.CompletionTokens,
            TotalTokens: chunk.Usage.TotalTokens,
        }
    }
    b, err := json.Marshal(dto)
    if err != nil { return err }
    if _, err := fmt.Fprintf(s.w, "data: %s\n\n", b); err != nil { return err }
    if s.flush != nil { s.flush() }
    return nil
}

func (s *StreamWriter) WriteDone() error {
    if _, err := io.WriteString(s.w, "data: [DONE]\n\n"); err != nil { return err }
    if s.flush != nil { s.flush() }
    return nil
}

// WriteError 在流中途出错时,以一个 OpenAI 格式 error chunk + [DONE] 关闭流。
func (s *StreamWriter) WriteError(e *apierr.Error) error {
    body := map[string]any{
        "error": map[string]any{
            "message": e.Message, "type": openAIErrType(e.Code), "code": openAIErrCode(e.Code),
        },
    }
    b, _ := json.Marshal(body)
    if _, err := fmt.Fprintf(s.w, "data: %s\n\n", b); err != nil { return err }
    if s.flush != nil { s.flush() }
    return s.WriteDone()
}
```

```go
        if _, exists := body[k]; !exists { body[k] = v }
    }
    return body
```

```go
func (s *chatStream) Next(ctx context.Context) (*ir.ChatChunk, error) {

        case <-ctx.Done(): return nil, adapter.ClassifyNetErr(ctx.Err())

        }

        return chunk, nil
    }
}
```

### 4.2 Anthropic 翻译

Anthropic Messages API 的关键差异:
- system 单独字段(顶层 `system: string`,**不**在 messages 数组里)
- content 永远是数组(即使纯文本也是 `[{type:"text", text:"..."}]`)
- assistant tool call 用 `content: [{type:"tool_use", id, name, input}]`
- user tool result 用 `content: [{type:"tool_result", tool_use_id, content}]`
- streaming 是多种 event type(`message_start` / `content_block_start` / `content_block_delta` / `content_block_stop` / `message_delta` / `message_stop`)

#### 4.2.1 request 翻译

```go
// internal/adapter/anthropic/translate_request.go
package anthropic

import (
    "github.com/proapi/proapi/internal/protocol/ir"
)

// toAnthropicRequest 把 IR ChatRequest 翻译成 Anthropic Messages 请求 body。
func toAnthropicRequest(req *ir.ChatRequest, stream bool) map[string]any {
    body := map[string]any{
        "model":      req.Model,
        "max_tokens": req.MaxTokens,
        "stream":     stream,
    }
    if body["max_tokens"].(int) == 0 {
        body["max_tokens"] = 4096  // Anthropic 强制必填,设默认
    }
    if req.Temperature != nil { body["temperature"] = *req.Temperature }
    if req.TopP != nil { body["top_p"] = *req.TopP }
    if len(req.Stop) > 0 { body["stop_sequences"] = req.Stop }

    // 1. 抽 system → 顶层
    var systemParts []map[string]any
    var msgs []map[string]any
    for _, m := range req.Messages {
        if m.Role == ir.RoleSystem {
            // Anthropic 支持 system 数组(prompt caching);M1 简化为单字符串拼接
            for _, p := range m.Content {
                if p.Type == ir.ContentText && p.Text != "" {
                    systemParts = append(systemParts, map[string]any{
                        "type": "text", "text": p.Text,
                    })
                }
            }
            continue
        }
        msgs = append(msgs, toAnthropicMessage(m))
    }
    if len(systemParts) == 1 {
        body["system"] = systemParts[0]["text"]
    } else if len(systemParts) > 1 {
        body["system"] = systemParts
    }
    body["messages"] = msgs

    // 2. tools 翻译
    if len(req.Tools) > 0 {
        tools := make([]map[string]any, 0, len(req.Tools))
        for _, t := range req.Tools {
            tools = append(tools, map[string]any{
                "name":        t.Function.Name,
                "description": t.Function.Description,
                "input_schema": t.Function.Parameters,
            })
        }
        body["tools"] = tools
    }
    // 3. tool_choice
    if req.ToolChoice != nil {
        body["tool_choice"] = translateToolChoice(req.ToolChoice)
    }
    return body
}

// toAnthropicMessage 把单个 IR Message 翻译成 Anthropic message。
func toAnthropicMessage(m ir.Message) map[string]any {
    role := m.Role
    if role == ir.RoleTool { role = "user" }  // tool result 当作 user message
    out := map[string]any{"role": role}
    var content []map[string]any
    // assistant 的 tool calls
    for _, tc := range m.ToolCalls {
        var input any
        _ = json.Unmarshal([]byte(tc.Function.Arguments), &input)
        if input == nil { input = map[string]any{} }
        content = append(content, map[string]any{
            "type":  "tool_use",
            "id":    tc.ID,
            "name":  tc.Function.Name,
            "input": input,
        })
    }
    // tool message 的 tool_result
    if m.Role == ir.RoleTool {
        var textContent any
        // m.Content 通常是单个 text part(tool 输出 JSON 字符串)
        if len(m.Content) == 1 && m.Content[0].Type == ir.ContentText {
            textContent = m.Content[0].Text
        } else {
            textContent = encodeContentForToolResult(m.Content)
        }
        content = append(content, map[string]any{
            "type":         "tool_result",
            "tool_use_id":  m.ToolCallID,
            "content":      textContent,
        })
    } else {
        // 普通 user / assistant content parts
        for _, p := range m.Content {
            switch p.Type {
            case ir.ContentText:
                content = append(content, map[string]any{"type": "text", "text": p.Text})
            case ir.ContentImageURL:
                content = append(content, toAnthropicImagePart(p.ImageURL))
            }
        }
    }
    out["content"] = content
    return out
}

// toAnthropicImagePart 处理 data URL(base64) → Anthropic image content。
// 仅支持 data:image/<mime>;base64,<payload> 与 https URL。
func toAnthropicImagePart(img ir.ImageURL) map[string]any {
    if strings.HasPrefix(img.URL, "data:") {
        // 解析 data URL
        comma := strings.IndexByte(img.URL, ',')
        if comma > 0 {
            head := img.URL[5:comma]  // image/png;base64
            payload := img.URL[comma+1:]
            mime := strings.SplitN(head, ";", 2)[0]
            return map[string]any{
                "type": "image",
                "source": map[string]any{
                    "type": "base64", "media_type": mime, "data": payload,
                },
            }
        }
    }
    return map[string]any{
        "type": "image",
        "source": map[string]any{"type": "url", "url": img.URL},
    }
}

func translateToolChoice(tc any) any {
    switch v := tc.(type) {
    case string:
        switch v {
        case "auto":     return map[string]any{"type": "auto"}
        case "required": return map[string]any{"type": "any"}
        case "none":     return map[string]any{"type": "none"}  // M1 fallback;Anthropic 无原生 none
        }
    case map[string]any:
        if v["type"] == "function" {
            if f, ok := v["function"].(map[string]any); ok {
                return map[string]any{"type": "tool", "name": f["name"]}
            }
        }
    }
    return map[string]any{"type": "auto"}
}
```

```go
package anthropic

// fromAnthropicResponse 把 Anthropic Messages 响应翻译为 IR ChatResponse。
func fromAnthropicResponse(raw []byte) (*ir.ChatResponse, error) {
    var d struct {
        ID    string `json:"id"`
        Model string `json:"model"`
        Role  string `json:"role"`
        Content []struct {
            Type  string         `json:"type"`
            Text  string         `json:"text,omitempty"`
            ID    string         `json:"id,omitempty"`
            Name  string         `json:"name,omitempty"`
            Input map[string]any `json:"input,omitempty"`
        } `json:"content"`
        StopReason string `json:"stop_reason"`
        Usage      struct {
            InputTokens         int `json:"input_tokens"`
            OutputTokens        int `json:"output_tokens"`
            CacheReadInputTokens  int `json:"cache_read_input_tokens"`
            CacheCreationInputTokens int `json:"cache_creation_input_tokens"`
        } `json:"usage"`
    }
    if err := json.Unmarshal(raw, &d); err != nil { return nil, err }
    msg := ir.Message{Role: ir.RoleAssistant}
    var hasToolCall bool
    for _, c := range d.Content {
        switch c.Type {
        case "text":
            msg.Content = append(msg.Content, ir.ContentPart{Type: ir.ContentText, Text: c.Text})
        case "tool_use":
            hasToolCall = true
            argsJSON, _ := json.Marshal(c.Input)
            msg.ToolCalls = append(msg.ToolCalls, ir.ToolCall{
                ID: c.ID, Type: "function",
                Function: ir.ToolCallFunction{Name: c.Name, Arguments: string(argsJSON)},
            })
        }
    }
    finish := mapAnthropicStopReason(d.StopReason)
    if hasToolCall && finish == ir.FinishStop { finish = ir.FinishToolCalls }
    return &ir.ChatResponse{
        ID: d.ID, Model: d.Model,
        Choices: []ir.Choice{{Index: 0, Message: msg, FinishReason: finish}},
        Usage: ir.Usage{
            PromptTokens: d.Usage.InputTokens + d.Usage.CacheReadInputTokens + d.Usage.CacheCreationInputTokens,
            CompletionTokens: d.Usage.OutputTokens,
            CachedTokens: d.Usage.CacheReadInputTokens,
            TotalTokens: d.Usage.InputTokens + d.Usage.OutputTokens +
                d.Usage.CacheReadInputTokens + d.Usage.CacheCreationInputTokens,
        },
    }, nil
}

func mapAnthropicStopReason(s string) string {
    switch s {
    case "end_turn":      return ir.FinishStop
    case "max_tokens":    return ir.FinishLength
    case "tool_use":      return ir.FinishToolCalls
    case "stop_sequence": return ir.FinishStop
    default:              return ir.FinishStop
    }
}
```

#### 4.2.3 stream 翻译

Anthropic SSE 事件类型多;策略是**保持状态机**:

```go
// internal/adapter/anthropic/stream.go
package anthropic

type anthropicStream struct {
    sse *adapter.SSEReader
    rc  io.ReadCloser
    // 累积态:跨多个 event 才能拼出一个完整 ir.ChatChunk
    id    string
    model string
    // 当前正在累积的 content block(index → state)
    blocks map[int]*blockState
    done   bool
    // queue 是已转好的 ir.ChatChunk 缓冲,可一次 SSE event 拆多个
    queue []*ir.ChatChunk
}

type blockState struct {
    typ      string  // "text" | "tool_use"
    toolID   string
    toolName string
}

func (s *anthropicStream) Next(ctx context.Context) (*ir.ChatChunk, error) {
    for {
        if len(s.queue) > 0 {
            c := s.queue[0]; s.queue = s.queue[1:]
            return c, nil
        }
        if s.done { return nil, io.EOF }
        select {
        case <-ctx.Done(): return nil, adapter.ClassifyNetErr(ctx.Err())
        default:
        }
        ev, err := s.sse.Next()
        if err != nil {
            if errors.Is(err, io.EOF) { s.done = true; return nil, io.EOF }
            return nil, adapter.ClassifyNetErr(err)
        }
        s.handleEvent(ev)
    }
}

func (s *anthropicStream) handleEvent(ev *adapter.Event) {
    switch ev.Event {
    case "message_start":
        var d struct {
            Message struct {
                ID    string `json:"id"`
                Model string `json:"model"`
                Usage struct {
                    InputTokens int `json:"input_tokens"`
                } `json:"usage"`
            } `json:"message"`
        }
        if err := json.Unmarshal([]byte(ev.Data), &d); err != nil { return }
        s.id = d.Message.ID; s.model = d.Message.Model
        // OpenAI SDK 期望首 chunk 有 role:"assistant"
        s.queue = append(s.queue, &ir.ChatChunk{
            ID: s.id, Model: s.model,
            Delta: ir.Delta{Role: ir.RoleAssistant},
        })
    case "content_block_start":
        var d struct {
            Index int `json:"index"`
            ContentBlock struct {
                Type string `json:"type"`
                ID   string `json:"id,omitempty"`
                Name string `json:"name,omitempty"`
            } `json:"content_block"`
        }
        if err := json.Unmarshal([]byte(ev.Data), &d); err != nil { return }
        s.blocks[d.Index] = &blockState{
            typ: d.ContentBlock.Type, toolID: d.ContentBlock.ID, toolName: d.ContentBlock.Name,
        }
        if d.ContentBlock.Type == "tool_use" {
            // 发一个空的 tool_call delta 让客户端知道 tool 出现
            s.queue = append(s.queue, &ir.ChatChunk{
                ID: s.id, Model: s.model,
                Delta: ir.Delta{ToolCalls: []ir.ToolCallDelta{{
                    Index: d.Index, ID: d.ContentBlock.ID,
                    Function: ir.ToolCallFunctionDelta{Name: d.ContentBlock.Name},
                }}},
            })
        }
    case "content_block_delta":
        var d struct {
            Index int `json:"index"`
            Delta struct {
                Type        string `json:"type"`
                Text        string `json:"text,omitempty"`
                PartialJSON string `json:"partial_json,omitempty"`
            } `json:"delta"`
        }
        if err := json.Unmarshal([]byte(ev.Data), &d); err != nil { return }
        switch d.Delta.Type {
        case "text_delta":
            s.queue = append(s.queue, &ir.ChatChunk{
                ID: s.id, Model: s.model,
                Delta: ir.Delta{Content: d.Delta.Text},
            })
        case "input_json_delta":
            s.queue = append(s.queue, &ir.ChatChunk{
                ID: s.id, Model: s.model,
                Delta: ir.Delta{ToolCalls: []ir.ToolCallDelta{{
                    Index: d.Index,
                    Function: ir.ToolCallFunctionDelta{Arguments: d.Delta.PartialJSON},
                }}},
            })
        }
    case "message_delta":
        var d struct {
            Delta struct {
                StopReason string `json:"stop_reason"`
            } `json:"delta"`
            Usage struct {
                OutputTokens int `json:"output_tokens"`
            } `json:"usage"`
        }
        if err := json.Unmarshal([]byte(ev.Data), &d); err != nil { return }
        s.queue = append(s.queue, &ir.ChatChunk{
            ID: s.id, Model: s.model,
            FinishReason: mapAnthropicStopReason(d.Delta.StopReason),
            Usage: &ir.Usage{CompletionTokens: d.Usage.OutputTokens},
        })
    case "message_stop":
        s.done = true
    }
}
```

> Anthropic stream 翻译是最复杂的一段;关键点:
> 1. 上游一个 event 可能映射 0 或多个 IR chunk → 用 queue buffer
> 2. tool 调用先发 ID + name(`content_block_start`),再发 partial JSON args(`content_block_delta`)
> 3. 客户端 SDK 期望按 OpenAI 顺序:role chunk → content chunks → finish chunk + usage chunk → [DONE]
> 4. 跨多 block index 时,通过 `Index` 字段区分(M1 单 tool 调用为主,M2 支持 parallel tools)

### 4.3 Gemini 翻译

Gemini API 关键差异:
- role 只有 `user` / `model`(无 `assistant`/`system`)
- system 通过顶层 `systemInstruction.parts[].text` 字段
- 单条消息的 content 是 `parts[]` 数组(text / inlineData / functionCall / functionResponse)
- tool 调用响应:`parts[].functionResponse{name, response}`
- 流式不是 SSE,是 JSON 数组 chunked(`?alt=sse` 时可走 SSE;M1 用 SSE 模式)

#### 4.3.1 request 翻译

```go
// internal/adapter/gemini/translate_request.go
package gemini

func toGeminiRequest(req *ir.ChatRequest) map[string]any {
    body := map[string]any{}
    // 1. system → systemInstruction
    var systemParts []map[string]any
    var contents []map[string]any
    for _, m := range req.Messages {
        if m.Role == ir.RoleSystem {
            for _, p := range m.Content {
                if p.Type == ir.ContentText && p.Text != "" {
                    systemParts = append(systemParts, map[string]any{"text": p.Text})
                }
            }
            continue
        }
        contents = append(contents, toGeminiContent(m))
    }
    if len(systemParts) > 0 {
        body["systemInstruction"] = map[string]any{"parts": systemParts}
    }
    body["contents"] = contents
    // 2. generationConfig
    gen := map[string]any{}
    if req.MaxTokens > 0 { gen["maxOutputTokens"] = req.MaxTokens }
    if req.Temperature != nil { gen["temperature"] = *req.Temperature }
    if req.TopP != nil { gen["topP"] = *req.TopP }
    if len(req.Stop) > 0 { gen["stopSequences"] = req.Stop }
    if req.ResponseFormat != nil && req.ResponseFormat.Type == "json_object" {
        gen["responseMimeType"] = "application/json"
    }
    if req.ResponseFormat != nil && req.ResponseFormat.Type == "json_schema" {
        gen["responseMimeType"] = "application/json"
        gen["responseSchema"] = req.ResponseFormat.Schema
    }
    if len(gen) > 0 { body["generationConfig"] = gen }
    // 3. tools
    if len(req.Tools) > 0 {
        decls := make([]map[string]any, 0, len(req.Tools))
        for _, t := range req.Tools {
            decls = append(decls, map[string]any{
                "name": t.Function.Name,
                "description": t.Function.Description,
                "parameters": t.Function.Parameters,
            })
        }
        body["tools"] = []map[string]any{{"functionDeclarations": decls}}
    }
    return body
}

func toGeminiContent(m ir.Message) map[string]any {
    role := "user"
    if m.Role == ir.RoleAssistant { role = "model" }
    if m.Role == ir.RoleTool { role = "user" }
    parts := []map[string]any{}
    // assistant 的 tool calls → functionCall parts
    for _, tc := range m.ToolCalls {
        var args map[string]any
        _ = json.Unmarshal([]byte(tc.Function.Arguments), &args)
        if args == nil { args = map[string]any{} }
        parts = append(parts, map[string]any{
            "functionCall": map[string]any{
                "name": tc.Function.Name, "args": args,
            },
        })
    }
    // tool message → functionResponse part
    if m.Role == ir.RoleTool {
        var response map[string]any
        if len(m.Content) == 1 && m.Content[0].Type == ir.ContentText {
            if err := json.Unmarshal([]byte(m.Content[0].Text), &response); err != nil {
                response = map[string]any{"content": m.Content[0].Text}
            }
        }
        parts = append(parts, map[string]any{
            "functionResponse": map[string]any{
                "name": m.Name, "response": response,
            },
        })
    } else {
        for _, p := range m.Content {
            switch p.Type {
            case ir.ContentText:
                parts = append(parts, map[string]any{"text": p.Text})
            case ir.ContentImageURL:
                parts = append(parts, toGeminiImagePart(p.ImageURL))
            }
        }
    }
    return map[string]any{"role": role, "parts": parts}
}

func toGeminiImagePart(img ir.ImageURL) map[string]any {
    if strings.HasPrefix(img.URL, "data:") {
        comma := strings.IndexByte(img.URL, ',')
        if comma > 0 {
            head := img.URL[5:comma]
            payload := img.URL[comma+1:]
            mime := strings.SplitN(head, ";", 2)[0]
            return map[string]any{
                "inlineData": map[string]any{
                    "mimeType": mime, "data": payload,
                },
            }
        }
    }
    // Gemini 不直接支持 http URL,只支持 file_data;data URL 是 M1 默认路径
    return map[string]any{
        "fileData": map[string]any{"mimeType": "image/jpeg", "fileUri": img.URL},
    }
}
```

```go
// internal/adapter/gemini/translate_response.go
package gemini

func fromGeminiResponse(raw []byte) (*ir.ChatResponse, error) {
    var d struct {
        Candidates []struct {
            Content struct {
                Role  string `json:"role"`
                Parts []struct {
                    Text         string         `json:"text,omitempty"`
                    FunctionCall *struct {
                        Name string         `json:"name"`
                        Args map[string]any `json:"args"`
                    } `json:"functionCall,omitempty"`
                } `json:"parts"`
            } `json:"content"`
            FinishReason string `json:"finishReason"`
        } `json:"candidates"`
        UsageMetadata struct {
            PromptTokenCount     int `json:"promptTokenCount"`
            CandidatesTokenCount int `json:"candidatesTokenCount"`
            TotalTokenCount      int `json:"totalTokenCount"`
            CachedContentTokenCount int `json:"cachedContentTokenCount"`
        } `json:"usageMetadata"`
    }
    if err := json.Unmarshal(raw, &d); err != nil { return nil, err }
    if len(d.Candidates) == 0 {
        return nil, apierr.New(apierr.CodeUpstreamError, "gemini returned no candidate")
    }
    cand := d.Candidates[0]
    msg := ir.Message{Role: ir.RoleAssistant}
    var hasFn bool
    for i, p := range cand.Content.Parts {
        if p.FunctionCall != nil {
            hasFn = true
            argsJSON, _ := json.Marshal(p.FunctionCall.Args)
            msg.ToolCalls = append(msg.ToolCalls, ir.ToolCall{
                ID: fmt.Sprintf("call_%d", i), Type: "function",
                Function: ir.ToolCallFunction{
                    Name: p.FunctionCall.Name, Arguments: string(argsJSON),
                },
            })
        } else if p.Text != "" {
            msg.Content = append(msg.Content, ir.ContentPart{Type: ir.ContentText, Text: p.Text})
        }
    }
    finish := mapGeminiFinish(cand.FinishReason)
    if hasFn && finish == ir.FinishStop { finish = ir.FinishToolCalls }
    return &ir.ChatResponse{
        Choices: []ir.Choice{{Index: 0, Message: msg, FinishReason: finish}},
        Usage: ir.Usage{
            PromptTokens: d.UsageMetadata.PromptTokenCount,
            CompletionTokens: d.UsageMetadata.CandidatesTokenCount,
            CachedTokens: d.UsageMetadata.CachedContentTokenCount,
            TotalTokens: d.UsageMetadata.TotalTokenCount,
        },
    }, nil
}

func mapGeminiFinish(s string) string {
    switch s {
    case "STOP":            return ir.FinishStop
    case "MAX_TOKENS":      return ir.FinishLength
    case "SAFETY":          return ir.FinishContentFilter
    case "RECITATION":      return ir.FinishContentFilter
    case "FUNCTION_CALL":   return ir.FinishToolCalls  // 旧版可能用
    default:                return ir.FinishStop
    }
}
```

#### 4.3.3 stream 翻译

Gemini 走 `?alt=sse` 后,每个 SSE event data 是完整的 `GenerateContentResponse` JSON。**与非流一样的 schema**,只是按 chunk 增量给。

```go
// internal/adapter/gemini/stream.go
package gemini

type geminiStream struct {
    sse  *adapter.SSEReader
    rc   io.ReadCloser
    done bool
}

func (s *geminiStream) Next(ctx context.Context) (*ir.ChatChunk, error) {
    if s.done { return nil, io.EOF }
    for {
        select {
        case <-ctx.Done(): return nil, adapter.ClassifyNetErr(ctx.Err())
        default:
        }
        ev, err := s.sse.Next()
        if err != nil {
            if errors.Is(err, io.EOF) { s.done = true; return nil, io.EOF }
            return nil, adapter.ClassifyNetErr(err)
        }
        chunk, end, err := parseGeminiStreamChunk(ev.Data)
        if err != nil { continue }
        if end { s.done = true }
        if chunk != nil { return chunk, nil }
    }
}

// parseGeminiStreamChunk 把一个 candidate response JSON 转 ir.ChatChunk。
//   - 上游每次发完整 candidate(含累积 text 或 delta);M1 假设是 delta 模式
//   - 实际:Gemini stream 模式发的是 incremental — 每条 part.text 是新增片段
func parseGeminiStreamChunk(data string) (*ir.ChatChunk, bool, error) {
    var d struct {
        Candidates []struct {
            Content struct {
                Parts []struct {
                    Text         string `json:"text,omitempty"`
                    FunctionCall *struct {
                        Name string         `json:"name"`
                        Args map[string]any `json:"args"`
                    } `json:"functionCall,omitempty"`
                } `json:"parts"`
            } `json:"content"`
            FinishReason string `json:"finishReason"`
        } `json:"candidates"`
        UsageMetadata *struct {
            PromptTokenCount int `json:"promptTokenCount"`
            CandidatesTokenCount int `json:"candidatesTokenCount"`
            TotalTokenCount int `json:"totalTokenCount"`
        } `json:"usageMetadata,omitempty"`
    }
    if err := json.Unmarshal([]byte(data), &d); err != nil { return nil, false, err }
    if len(d.Candidates) == 0 { return nil, false, nil }
    cand := d.Candidates[0]
    chunk := &ir.ChatChunk{}
    for i, p := range cand.Content.Parts {
        if p.Text != "" {
            chunk.Delta.Content += p.Text
        }
        if p.FunctionCall != nil {
            argsJSON, _ := json.Marshal(p.FunctionCall.Args)
            chunk.Delta.ToolCalls = append(chunk.Delta.ToolCalls, ir.ToolCallDelta{
                Index: i, ID: fmt.Sprintf("call_%d", i),
                Function: ir.ToolCallFunctionDelta{
                    Name: p.FunctionCall.Name, Arguments: string(argsJSON),
                },
            })
        }
    }
    finished := cand.FinishReason != ""
    if finished {
        chunk.FinishReason = mapGeminiFinish(cand.FinishReason)
    }
    if d.UsageMetadata != nil {
        chunk.Usage = &ir.Usage{
            PromptTokens: d.UsageMetadata.PromptTokenCount,
            CompletionTokens: d.UsageMetadata.CandidatesTokenCount,
            TotalTokens: d.UsageMetadata.TotalTokenCount,
        }
    }
    return chunk, finished, nil
}
```

Azure OpenAI 与 OpenAI 主要差异:

```go
// buildEndpoint 从 cred.Extra 解析 deployment + apiVersion。
//   - cred.Extra["deployments"] 是 JSON: {"gpt-4": "my-deploy-name", ...}
//   - cred.Extra["api_version"] 默认 "2024-08-01-preview"
//   - cred.BaseURL = "https://{resource}.openai.azure.com"
func (a *Azure) buildEndpoint(model, path string, cred adapter.Credential) (url, key string, err error) {
    deploys, err := parseDeployments(cred.Extra["deployments"])
    if err != nil {
        return "", "", apierr.New(apierr.CodeChannelMisconfig, "azure deployments invalid: "+err.Error())
    }
    deployment, ok := deploys[model]
    if !ok {
        return "", "", apierr.New(apierr.CodeChannelMisconfig,
            "no Azure deployment for model "+model)
    }
    apiVersion := cred.Extra["api_version"]
    if apiVersion == "" { apiVersion = "2024-08-01-preview" }
    base := cred.BaseURL
    if base == "" {
        return "", "", apierr.New(apierr.CodeChannelMisconfig, "azure base_url required")
    }
    url = fmt.Sprintf("%s/openai/deployments/%s/%s?api-version=%s",
        strings.TrimRight(base, "/"), deployment, path, apiVersion)
    return url, cred.APIKey, nil
}

func parseDeployments(s string) (map[string]string, error) {
    if s == "" { return map[string]string{}, nil }
    var m map[string]string
    if err := json.Unmarshal([]byte(s), &m); err != nil { return nil, err }
    return m, nil
}
```

### 4.5 Zhipu 适配器(JWT 签名)

Zhipu(智谱)GLM-4 API 使用 OpenAI 兼容的 endpoint(`https://open.bigmodel.cn/api/paas/v4/chat/completions`),但 auth 头是 JWT。

```go
// internal/adapter/zhipu/auth.go
package zhipu

import (
    "encoding/base64"
    "encoding/json"
    "errors"
    "strings"
    "time"

    "github.com/golang-jwt/jwt/v5"
)

const jwtTTL = 15 * time.Minute

// SignJWT 用 api_key("id.secret" 形式)生成一个短效 JWT。
//   - alg = HS256
//   - header.sign_type = "SIGN"
//   - payload = {api_key:<id>, exp:<unix_ms>, timestamp:<unix_ms>}
func SignJWT(apiKey string, now time.Time) (string, error) {
    parts := strings.SplitN(apiKey, ".", 2)
    if len(parts) != 2 {
        return "", errors.New("zhipu api_key must be in form <id>.<secret>")
    }
    id, secret := parts[0], parts[1]
    expMs := now.Add(jwtTTL).UnixMilli()
    nowMs := now.UnixMilli()
    claims := jwt.MapClaims{
        "api_key":   id,
        "exp":       expMs,
        "timestamp": nowMs,
    }
    token := jwt.NewWithClaims(jwt.SigningMethodHS256, claims)
    token.Header["sign_type"] = "SIGN"
    return token.SignedString([]byte(secret))
}
```

```go
// internal/adapter/zhipu/zhipu.go
package zhipu

const defaultBaseURL = "https://open.bigmodel.cn/api/paas/v4"

type Zhipu struct {
    inner *openai.OpenAI
    clock clock.Clock
    // jwtCache：apiKey → (jwt, expiresAt);避免每次签 JWT。
    cache sync.Map  // key: apiKey, value: cachedJWT
}

type cachedJWT struct {
    token    string
    expireAt time.Time
}

func New(clk clock.Clock) *Zhipu {
    return &Zhipu{inner: openai.New(), clock: clk}
}

func (a *Zhipu) Name() string { return "zhipu" }
func (a *Zhipu) Capabilities() adapter.Capability {
    return adapter.CapChat | adapter.CapStream | adapter.CapEmbedding | adapter.CapToolUse | adapter.CapVision
}
func (a *Zhipu) SupportedModels() []string { return []string{"glm-*", "embedding-*"} }

func (a *Zhipu) Chat(ctx context.Context, req *ir.ChatRequest, cred adapter.Credential) (*ir.ChatResponse, error) {
    tok, err := a.token(cred.APIKey)
    if err != nil { return nil, apierr.New(apierr.CodeChannelMisconfig, err.Error()) }
    base := cred.BaseURL
    if base == "" { base = defaultBaseURL }
    url := strings.TrimRight(base, "/") + "/chat/completions"
    return a.inner.ChatWithEndpoint(ctx, req, tok, url, "Authorization", "Bearer ")
}

// token 返回缓存的 JWT;过期则重新签。
func (a *Zhipu) token(apiKey string) (string, error) {
    now := a.clock.Now()
    if v, ok := a.cache.Load(apiKey); ok {
        c := v.(cachedJWT)
        if c.expireAt.After(now.Add(1 * time.Minute)) {  // 1min 安全边界
            return c.token, nil
        }
    }
    tok, err := SignJWT(apiKey, now)
    if err != nil { return "", err }
    a.cache.Store(apiKey, cachedJWT{token: tok, expireAt: now.Add(jwtTTL)})
    return tok, nil
}
```

### 4.8 Stream 实现统一约定

每家 adapter 的 stream:
1. 用 `streamClient`(Timeout=0)发请求
2. 检查 status code(非 200 早出错)
3. 包装响应 body 为 `chatStream` struct,持有 `*adapter.SSEReader` + `io.ReadCloser`
4. `Next(ctx)` 内每次 `sse.Next()`,JSON 解析 chunk → IR
5. `[DONE]` 标志 → `io.EOF`
6. `Close()` → 关闭 body

**生命周期**:`relay.ChatStream` 取 `StreamReader` → handler `defer stream.Close()` → 循环 `Next` 写 SSE → 写 `[DONE]`。

```go
func (h *Handler) streamChat(c *gin.Context, req *ir.ChatRequest) {
    view, _ := token.FromContext(c)
    stream, err := h.relay.ChatStream(c.Request.Context(), req, relay.SelectInput{
        UserID: view.UserID, TokenID: view.ID, GroupID: groupIDFromCtx(c),
    })
    if err != nil { middleware.SetErr(c, apierr.Wrap(err)); return }
    defer stream.Close()

    c.Header("Content-Type", "text/event-stream")
    c.Header("Cache-Control", "no-cache")
    c.Header("Connection", "keep-alive")
    c.Header("X-Accel-Buffering", "no")  // Nginx 不缓冲
    flusher, _ := c.Writer.(http.Flusher)

    sw := openai.NewStreamWriter(c.Writer, flusher.Flush)

    for {
        chunk, err := stream.Next(c.Request.Context())
        if errors.Is(err, io.EOF) { break }
        if err != nil {
            // 流中途出错:写一个 error chunk + [DONE]
            sw.WriteError(apierr.Wrap(err))
            return
        }
        if err := sw.WriteChunk(chunk); err != nil { return }  // 客户端断开
    }
    sw.WriteDone()
}
```

## 11. 关键决策

### 11.1 IR 永远是中间表示,不传出包

**决策**:adapter 与 protocol 都依赖 `internal/protocol/ir`;handler 只读 OpenAI DTO,内部转 IR,IR 不应出现在 HTTP 响应序列化路径。

理由:
- IR 是设计层抽象,字段可能演化(M2 加 image generation / audio);改 IR 不影响入口协议契约
- 入口协议 DTO 与 IR 解耦,允许 M2 加 Anthropic / Gemini 入口协议时各自有自己的 DTO

### 11.2 ExtraParams 透传策略

**决策**:`ir.ChatRequest.ExtraParams` 在 decode 时**不填**(`DisallowUnknownFields` 严格);adapter 在 `buildChatBody` 透传时**显式忽略**入口路径的 extra,**仅在管理端 / 测试时**有人塞东西进去(为后台调试预留)。

理由:
- 客户端透传任意字段到上游 = 风险源(可能注入 cost 高的字段)
- M1 严格;M2 加一个 setting `openai.passthrough_fields = ["frequency_penalty", ...]` 白名单放宽

### 11.3 stream usage 一定要拿

**决策**:每家 adapter 在 stream 请求里**强制**附加 `stream_options.include_usage = true`(OpenAI 兼容)或对应字段。

理由:
- 计费(M1-06)需要精确 token 数;若上游不发,只能用本地 tokenizer 估,不准
- 不发 usage 的上游(Anthropic / Gemini)有自己的 stream usage 事件,各 adapter 在 stream 实现里抽 usage 字段透出

### 11.4 Azure deployment 映射在 channel.extra

**决策**:Azure 的 `model 名 → deployment 名` 映射存 `channels.extra.deployments`(JSON map),adapter 解析:

```json
{
  "deployments": {"gpt-4o": "prod-gpt4o", "gpt-4o-mini": "prod-mini"},
  "api_version": "2024-08-01-preview"
}
```

理由:
- 不与 `channel_model_mappings.upstream_model` 冲突:`upstream_model` 是 client_model 重写(`gpt-4o-2024-11-20 → gpt-4o`);`deployments` 是 azure 私有部署 ID
- 多个 Azure 渠道可以共用 client_model(`gpt-4o`)但部署 ID 不同 → 由 channel.extra 各自配
- 后台 UI(M1-09)对 azure 渠道显示 deployments 编辑 widget

### 11.5 doubao 模型 = endpoint ID

**决策**:豆包 endpoint ID(`ep-xxx`)由 `channels.channel_model_mappings.upstream_model` 写入,adapter 无需特殊处理。

理由:
- ep-xxx 与模型字典里的 `doubao-pro-32k` 解耦 — 一个 client_model 可在多个渠道映射到不同 ep
- adapter 拿到 IR 时 `req.Model` 已经是 `ep-xxx`(relay 应用 ModelMap 后)

### 11.6 Anthropic system 是顶层 → 翻译时抽出

**决策**:IR `messages` 数组中的 `role:"system"` 消息,Anthropic adapter 翻译时**抽出**放入 `system` 顶层字段;Anthropic 响应不含 system → IR 不需要反向。

理由:
- Anthropic 不允许 system role 在 messages 数组里;若直接传会 400
- IR 保持 OpenAI 风格(system in messages)— 翻译层负责差异

### 11.7 tool_use 双向语义

**决策**:
- IR `Message.ToolCalls`(assistant) ↔ Anthropic `content[].type="tool_use"` / Gemini `parts[].functionCall`
- IR `Message{Role:"tool", ToolCallID, Content:text}` ↔ Anthropic `role="user", content[].type="tool_result"` / Gemini `role="user", parts[].functionResponse`

理由:OpenAI / Anthropic / Gemini 都有 tool 概念但承载位置不同;翻译层封装差异让上层只感知 OpenAI 语义。

### 11.8 streamReader.Close 必须由 handler 调

**决策**:`StreamReader.Close()` 不在 adapter 内部自动调,**handler defer 调用**(否则 HTTP 连接泄漏)。

理由:
- adapter 不知道 handler 何时不再 Next(可能客户端断开)
- 显式 defer 保证清理;`io.EOF` 后 Next 是幂等的

### 11.9 错误内嵌的 raw body 截断

**决策**:`ClassifyHTTPStatus` 把上游 raw body 截至 512 byte 放入 `apierr.Error.Details`;响应给客户端时 details **不出现在 OpenAI error envelope**(只出现在管理 API JSON 错误)。

理由:
- 客户端通常不需要原始上游 body(可能含敏感凭证)
- 但内部日志(error_logs.context)需要详情用于排查
- 详细 body 用 `apierr.Error.Details` 字段承载,handler 决定是否暴露

### 11.10 HTTP redirect 不跟随

**决策**:adapter 的 HTTP client 用 `CheckRedirect: http.ErrUseLastResponse`,3xx 不跟随。

理由:
- OpenAI 不会发 redirect;Azure / Anthropic / Gemini 也无
- 若上游突然发 redirect 多半是 DNS 劫持 / 钓鱼,**早 fail 比悄悄跟随好**
- Go default 跟随 10 次 → 改为不跟随,直接当上游错处理

### 11.11 stream client 与非流 client 分离

**决策**:每家 adapter 有 `httpClient`(Timeout=60s)+ `streamClient`(Timeout=0),共用 Transport。

理由:
- `http.Client.Timeout` 是端到端(包括 body 读),流式可能持续几分钟,会被 Timeout 切断
- 流式靠 `ctx`(请求超时)+ idle timeout(M2 加)控制
- 共用 Transport 复用连接池

### 11.12 model_aliases 推 M2

**决策**:本 spec **不建** `model_aliases` 表,**不实现**别名逻辑。

理由:
- 别名场景(`gpt-4o → gpt-4o-2024-11-20`)实际可由 `channel_model_mappings.upstream_model` 替代 — 客户端写 `gpt-4o`,渠道映射到具体版本
- 别名表带来另一层查找,管理后台得多一页,M1 复杂度 +1 不值
- 总纲 §2.20 标记为"可选";本 spec 决定**M1 不实现,M2 评估**

> 回写 [总纲 §2.20](./2026-05-21-里程碑1-总体设计纲要.md#220--model_aliases可选m1-可选实现):`M1 决策:不实现,推 M2`。

### 11.13 tokenizer:OpenAI 真实,其余近似

**决策**:见 §4.9 — 仅 OpenAI 系列接 `tiktoken-go`;其余字符 ÷ 4 近似。

理由(再展开):
- tiktoken-go 包大小 ~2MB,启动 OK
- Anthropic / Gemini 无成熟 Go tokenizer;sentencepiece-go 体积更大,M1 不引入
- 估算用于 reserve;偏差 ±20% 由 commit 阶段实际 usage 修正
- M2 评估替代方案(prebuilt protobuf 模型 + 轻量 sentencepiece runtime)

### 11.14 完整模型字典 seed 在 migration

**决策**:32 条 model_catalogs seed 写在 migration `000023_seed_model_catalogs.{up,down}.sql` 里,**不**走代码 `seed.go` 注入。

理由:
- migration 一次性应用,所有部署都一致
- 代码 seed 在多实例启动时会冲突(谁先谁赢);用 DB 唯一索引 + ON DUPLICATE KEY UPDATE 在 migration 层处理更干净
- 后续模型新增由管理后台 CRUD(M1-09)处理;新模型不需要重新 migration

### 11.15 OpenAI 严格字段校验默认开

**决策**:`DecodeChat` 默认 `DisallowUnknownFields`;由 setting `openai.allow_unknown_fields` 放宽。

理由:
- 严格能帮助客户端早发现 typo / API 误用
- 长尾客户端确实会发不认识的字段(如 `presence_penalty`)— 由运维通过 setting 一键放宽
- 放宽时所有未知字段被丢弃(不透传给上游),避免被注入恶意参数

### 11.16 SSE 写入 flush 频率

**决策**:每写一个 chunk 立即 flush;不批量。

理由:
- 流式核心价值是低延迟可视;批量会反向破坏体验
- HTTP/1.1 + chunked encoding 单 chunk 写 ~几十 byte 不会瓶颈
- Nginx 中关闭 buffering(已在 handler 设 `X-Accel-Buffering: no`)

### 11.17 客户端断开行为

**决策**:`handler` 通过 `c.Request.Context()` 监听断开;Context 被 cancel 时,`stream.Next` 立刻返回 `ClassifyNetErr(ctx.Err())` → `CodeUpstreamTimeout`;adapter 内 HTTP request 也被 cancel,上游连接随之关闭。

理由:
- 不能在客户端断开后继续消费上游 token(浪费 quota)
- ctx 串联端到端:client → handler → relay → adapter → http.Request

### 11.18 完整模型支持的 family

**决策**:M1 范围仅 `chat` + `embed`;`image / audio / rerank` 在模型字典留 family 字段,但实际 adapter 路径不支持 — 客户端调用相关模型直接返 `CodeModelNotSupported`。

理由:
- 多模态 adapter 复杂度高(参数 / endpoint / SSE 模式都不同),与本 spec 范围冲突
- M2 一并开 image / audio,届时所有 adapter 一起扩展

### 11.19 BaseURL 优先级

**决策**:adapter `Chat` 时,base URL 取优先顺序:`cred.BaseURL`(渠道配)→ adapter 默认。

理由:
- 部分公司用 OpenAI 反代理(`api.openai-proxy.com`);通过 channel.base_url 注入
- adapter 不读 setting(避免间接耦合 setting → adapter)

### 11.20 Provider name 是 channel.provider 的小写字符串

**决策**:`adapter.Name()` 返回值与 `channels.provider` 列值精确匹配,**小写**,**不含连字符以外字符**。9 家固定值:`openai / azure / anthropic / gemini / deepseek / moonshot / zhipu / qwen / doubao`。

理由:
- 直接 string lookup 简单可靠
- 与种子数据 / migration / 前端选择器都一致
