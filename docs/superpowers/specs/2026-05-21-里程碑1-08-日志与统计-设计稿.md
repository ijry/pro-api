# 里程碑 M1-08 日志与统计

## 1. 目标与范围

### 1.1 一句话

**M1 范围内"看"系统的唯一入口** — 把请求/消费/错误三类事件落到分区表里,
通过非阻塞 batch flusher 顶住峰值,再提供管理员侧 8 个聚合查询接口与用户侧
2 个个人日志接口,前后台据此呈现"日志、统计、看板"。

### 1.2 范围

属于本 spec 的(11 件事):

1. **`request_logs / usage_logs` 同表分区表**(总纲 §2.8)+ migration `000009_create_request_logs.{up,down}.sql`
2. **`error_logs`**(总纲 §2.9)+ migration `000010_create_error_logs.{up,down}.sql`
3. `internal/log/` 包:`Store` 接口 + DB 实现(MySQL + PG)
4. **异步 batch flusher**:channel(cap 4096) + N=2 worker goroutine,batch 100 条 或 1s flush
5. **非阻塞 Write / WriteError**:channel `select default` 满则 drop + counter `log_dropped_total`
6. **Query keyset 分页**:多条件筛选 + cursor (id, created_at) 翻页,WHERE 必带时间范围保证分区裁剪
7. **分区维护**:`EnsurePartitions(year, month)` — 启动时建当月 + 后 12 个月,每日凌晨 4 点 cron 滚动检查
8. **ClickHouse 适配器接口预留**:只声明 interface,不实现(M3 加 CH 实现)
9. **管理员侧 HTTP handler**:
   - `GET /api/admin/logs/requests` / `GET /api/admin/logs/errors` / `GET /api/admin/logs/audit`
   - `GET /api/admin/stats/overview` / `GET /api/admin/stats/timeseries`
   - `GET /api/admin/stats/by_model` / `GET /api/admin/stats/by_channel` / `GET /api/admin/stats/by_user`
   - `GET /api/admin/stats/export?format=csv&...`(流式 CSV,单次最多 1M 行)
10. **用户侧 HTTP handler**:
    - `GET /api/user/logs/requests` / `GET /api/user/logs/errors`(user_id 强制注入)
11. **优雅关停**:`Store.Close()` 关 channel → 等所有 worker drain 完剩余记录再返回

### 1.3 不属于本 spec(明确排除项)

- ❌ **ClickHouse 实际实现** — 接口预留,实现放 M3;本 spec 不写 CH 客户端代码
- ❌ **实时大屏 / WebSocket 推送** — M3 提供
- ❌ **OpenTelemetry / trace 链路** — M3 提供
- ❌ **`audit_logs` 表 DDL 与写入逻辑** — 已在 [M1-01 §2.2](./2026-05-21-里程碑1-01-基础设施增量-设计稿.md#22-audit_logs-迁移) 建,本 spec 只**读**它(供后台 `GET /api/admin/logs/audit`)
- ❌ **audit 后台 UI** — 在 M1-09 后台前端 spec
- ❌ **日志保留期自动清理(drop 旧分区 cron)** — 总纲 §2.8 明确"M1 只做分区,不做清理,清理放 M2"
- ❌ **关联查询导出明细 PDF / Excel** — 仅 CSV 流式
- ❌ **复杂 GroupBy 多维下钻** — M1 只做 by_model / by_channel / by_user 三类预定义聚合
- ❌ `request_logs` 数据 sink 到外部消息队列(Kafka 等)— M3
- ❌ 日志数据的 PII 脱敏 — `error_logs.context` 由调用方在传入前自行脱敏

### 1.5 在 M1 依赖中的位置

参见 [总纲 §10.1](./2026-05-21-里程碑1-总体设计纲要.md#101-依赖图),M1-08 在 **C 批**(并行),前置批 A/B 已交付,**直接被 M1-09(后台前端)/ M1-10(用户前台)消费**。同批的 M1-04 ~ M1-07 在 relay 链路里调用 `log.Store.Write/WriteError`,本 spec 提供他们使用的接口签名与实现。

### 1.6 设计原则

- **非阻塞优先**:relay/handler 路径上的 `Write` / `WriteError` 必须不阻塞。宁可丢日志,不影响请求耗时
- **写多读少**:日志表查询是后台动作,QPS 远低于写。优化目标 → 写吞吐 > 单条查询延迟
- **DB 中立**:本包是 MySQL/PG 双驱动 — 所有方言差异封装在 `partition_*.go` 与 `query.go` 内部
- **可替换实现**:接口与 DB 实现解耦,M3 加 ClickHouse 时切换实现即可
- **分区裁剪**:任何 Query 必带 `created_at` 范围,否则被中间件拒绝(避免全表扫导致 OOM)

### 2.1 字段定义引用

字段定义沿用 [总纲 §2.8(`request_logs`)](./2026-05-21-里程碑1-总体设计纲要.md#28-request_logs-usage_logs) 与 [§2.9(`error_logs`)](./2026-05-21-里程碑1-总体设计纲要.md#29-error_logs)。本 spec **不重复字段表**,只给出 migration DDL 与分区策略。

### 2.2 `000009_create_request_logs.{up,down}.sql`(MySQL)

```sql
-- migrations/mysql/000009_create_request_logs.up.sql
CREATE TABLE IF NOT EXISTS request_logs (
    id                    BIGINT       NOT NULL,
    created_at            DATETIME(3)  NOT NULL,
    user_id               BIGINT       NOT NULL,
    token_id              BIGINT       NOT NULL,
    dept_id               BIGINT,
    group_id              BIGINT,
    event_type            TINYINT      NOT NULL DEFAULT 0,
    client_model          VARCHAR(128) NOT NULL,
    upstream_model        VARCHAR(128) NOT NULL DEFAULT '',
    channel_id            BIGINT,
    protocol              VARCHAR(16)  NOT NULL DEFAULT 'openai',
    endpoint              VARCHAR(64)  NOT NULL,
    ip                    VARCHAR(45)  NOT NULL DEFAULT '',
    user_agent            VARCHAR(256) NOT NULL DEFAULT '',
    status_code           SMALLINT     NOT NULL DEFAULT 0,
    latency_ms            INT          NOT NULL DEFAULT 0,
    ttft_ms               INT          NOT NULL DEFAULT 0,
    stream                TINYINT(1)   NOT NULL DEFAULT 0,
    input_tokens          INT          NOT NULL DEFAULT 0,
    output_tokens         INT          NOT NULL DEFAULT 0,
    cached_tokens         INT          NOT NULL DEFAULT 0,
    reasoning_tokens      INT          NOT NULL DEFAULT 0,
    total_quota           BIGINT       NOT NULL DEFAULT 0,
    billing_input_ratio   DECIMAL(10,4) NOT NULL DEFAULT 0,
    billing_output_ratio  DECIMAL(10,4) NOT NULL DEFAULT 0,
    billing_group_ratio   DECIMAL(10,4) NOT NULL DEFAULT 1,
    error_code            INT          NOT NULL DEFAULT 0,
    error_msg             VARCHAR(512) NOT NULL DEFAULT '',
    trace_id              VARCHAR(64)  NOT NULL DEFAULT '',
    PRIMARY KEY (id, created_at),
    KEY idx_req_user_time      (user_id, created_at),
    KEY idx_req_token_time     (token_id, created_at),
    KEY idx_req_channel_time   (channel_id, created_at),
    KEY idx_req_clientmodel_time (client_model, created_at),
    KEY idx_req_event_time     (event_type, created_at)
)
ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
PARTITION BY RANGE (TO_DAYS(created_at)) (
    -- 实际分区由应用启动时 ALTER TABLE 动态创建,这里给一个最小起点
    -- 必须留一个"过去边界"分区,避免插入历史数据时报错
    PARTITION p_min      VALUES LESS THAN (TO_DAYS('2026-01-01')),
    PARTITION p_2026_05  VALUES LESS THAN (TO_DAYS('2026-06-01')),
    PARTITION p_max      VALUES LESS THAN MAXVALUE
);
```

**关键决策**:
- `PRIMARY KEY (id, created_at)` — MySQL 分区表要求分区键必须在所有 UNIQUE KEY(含 PK)中;`id` 单字段 PK 违反此约束。所以用 `(id, created_at)` 复合 PK
- 所有二级索引都带 `created_at` 后缀:支持索引前缀失败回落时仍能做分区裁剪
- 初始 DDL 内仅声明 `p_min` / 当月分区 `p_2026_05` / `p_max`(MAXVALUE 兜底) — 真实分区由 `EnsurePartitions` 在应用启动时滚动创建(详见 §4.4)
- `p_max` MAXVALUE 分区是兜底:如果应用挂了没及时建分区,新写入不会失败(只是该分区会膨胀)

> **历史数据反写**:`p_min` 涵盖 2026-01 之前所有历史 — 测试 fixture 或回灌历史数据时不会插入失败。生产环境若 created_at 在 2026-01 之前是异常,本 spec 不处理。

down:

```sql
-- migrations/mysql/000009_create_request_logs.down.sql
DROP TABLE IF EXISTS request_logs;
```

## 3. 接口契约

### 3.1 `log.Store`(本 spec 定稿,扩展自总纲 §4.7)

```go
// internal/log/store.go
package log

import (
    "context"
    "io"
    "time"
)

// Store 是日志读写主入口。
// 实现:
//   - dbStore(本 spec):MySQL / PG
//   - chStore(M3):ClickHouse(本 spec 仅 type 声明)
type Store interface {
    // Write 非阻塞写入一条 request log。channel 满时静默丢弃并 counter++。
    // 调用方可传 nil ctx(内部使用 background ctx 提交到 worker)。
    Write(ctx context.Context, e Event)

    // WriteError 非阻塞写入一条 error log。语义同 Write。
    WriteError(ctx context.Context, e ErrorEvent)

    // Query 多条件分页查询 request_logs(管理 + 用户共用,user_id 注入在 handler 层)。
    // 必须传入 q.From / q.To 时间范围,否则返回 ErrTimeRangeRequired。
    Query(ctx context.Context, q Query) (QueryResult, error)

    // QueryErrors 同 Query,查 error_logs。
    QueryErrors(ctx context.Context, q ErrorQuery) (ErrorQueryResult, error)

    // QueryAudits 查 audit_logs(M1-01 表)。本 spec 提供查询能力,
    // 写入在各业务模块,故只读。
    QueryAudits(ctx context.Context, q AuditQuery) (AuditQueryResult, error)

    // Stats* 聚合接口
    StatsOverview(ctx context.Context, q OverviewQuery) (Overview, error)
    StatsTimeseries(ctx context.Context, q TimeseriesQuery) (Timeseries, error)
    StatsByModel(ctx context.Context, q GroupQuery) (GroupResult, error)
    StatsByChannel(ctx context.Context, q GroupQuery) (GroupResult, error)
    StatsByUser(ctx context.Context, q GroupQuery) (GroupResult, error)

    // ExportCSV 流式导出 request_logs。把 CSV 一行一行写到 w。
    // 最多导出 maxRows(由配置 / 默认 1_000_000)。超过截断 + 在 trailer 写 NOTE。
    ExportCSV(ctx context.Context, q Query, w io.Writer) (rowsWritten int64, err error)

    // EnsurePartitions 检查并创建 [start, start+months] 范围内的所有月份分区。
    // 启动时与每日 cron 调用。幂等。
    EnsurePartitions(ctx context.Context, start time.Time, months int) error

    // Close 优雅关停:停止接收新事件,等所有 worker drain 完返回。
    // 超时由调用方 ctx 控制。
    Close() error
}
```

### 3.2 Query / Result 数据结构

```go
// internal/log/event.go(续)

// Query 是 request_logs 查询请求。
type Query struct {
    UserID     *int64    // nil = 不过滤;用户侧 handler 必须强制注入
    TokenID    *int64
    ChannelID  *int64
    ClientModel string   // "" = 不过滤;支持通配 "gpt-4*"(用 LIKE 'gpt-4%')
    EventType  *int8     // 0=request 1=usage;nil = 全部
    StatusCode *int      // HTTP status;nil = 全部
    From       time.Time // 必填
    To         time.Time // 必填
    TraceID    string    // "" = 不过滤

    // Keyset 分页(详见 §4.5)
    Cursor     *Cursor
    PageSize   int       // 默认 50,最大 200
    // 排序固定:created_at DESC, id DESC(分区裁剪 + 唯一)
}

// Cursor 是 keyset 翻页游标。next-page 用 last item 的 (CreatedAt, ID)。
type Cursor struct {
    CreatedAt time.Time
    ID        int64
}
```

## 4. 关键算法

### 4.1 异步 batch flusher 总览

```
                ┌─ Write(e) ─────┐
relay/handler ─┤                 ├─→ select {
                └─ WriteError(e) ┘     case chReq <- e:  enqueued
                                        case chErr <- e:  enqueued
                                        default:           dropped ++ counter
                                      }

chReq (cap=4096) ────┬──→ worker 0 ──→ batch INSERT (100 rows or 1s)
                     └──→ worker 1 ──→ ...

chErr (cap=4096) ────┬──→ workerErr 0
                     └──→ workerErr 1
```

- channel cap = **4096**(可由 setting 覆盖)
- worker 数 N=**2**(请求与错误各 2)
- batch size = **100** 条(满即 flush)
- max latency = **1s**(无论是否满)
- 失败重试 **3 次**(指数退避 100ms / 200ms / 400ms),仍失败计数 + 日志

### 4.3 Worker 主循环(完整代码)

```go
// internal/log/flusher.go(续)

func (f *flusher) start() {
    for i := 0; i < f.workersReq; i++ {
        f.wg.Add(1)
        go f.workerReq(i)
    }
    for i := 0; i < f.workersErr; i++ {
        f.wg.Add(1)
        go f.workerErr(i)
    }
    // 定期上报 queue depth 给 Prometheus
    f.wg.Add(1)
    go f.depthReporter()
}

func (f *flusher) workerReq(idx int) {
    defer f.wg.Done()

    batch := make([]Event, 0, f.batchSize)
    tick := time.NewTicker(f.interval)
    defer tick.Stop()

    flush := func() {
        if len(batch) == 0 { return }
        f.doFlushReq(batch)
        batch = batch[:0]
    }

    for {
        select {
        case e, ok := <-f.chReq:
            if !ok {
                // channel 已 close,drain 完剩余
                flush()
                return
            }
            batch = append(batch, e)
            if len(batch) >= f.batchSize {
                flush()
            }
        case <-tick.C:
            flush()
        case <-f.stopCh:
            // stop 信号 — drain channel 然后退出
            for {
                select {
                case e, ok := <-f.chReq:
                    if !ok {
                        flush(); return
                    }
                    batch = append(batch, e)
                    if len(batch) >= f.batchSize {
                        flush()
                    }
                default:
                    flush()
                    return
                }
            }
        }
    }
}

func (f *flusher) workerErr(idx int) {
    defer f.wg.Done()

    batch := make([]ErrorEvent, 0, f.batchSize)
    tick := time.NewTicker(f.interval)
    defer tick.Stop()

    flush := func() {
        if len(batch) == 0 { return }
        f.doFlushErr(batch)
        batch = batch[:0]
    }

    // 主循环结构同 workerReq,略
    for {
        select {
        case e, ok := <-f.chErr:
            if !ok { flush(); return }
            batch = append(batch, e)
            if len(batch) >= f.batchSize { flush() }
        case <-tick.C:
            flush()
        case <-f.stopCh:
            for {
                select {
                case e, ok := <-f.chErr:
                    if !ok { flush(); return }
                    batch = append(batch, e)
                default:
                    flush(); return
                }
            }
        }
    }
}

func (f *flusher) depthReporter() {
    defer f.wg.Done()
    t := time.NewTicker(10 * time.Second)
    defer t.Stop()
    for {
        select {
        case <-t.C:
            queueDepth.WithLabelValues("request").Set(float64(len(f.chReq)))
            queueDepth.WithLabelValues("error").Set(float64(len(f.chErr)))
        case <-f.stopCh:
            return
        }
    }
}

func (f *flusher) doFlushReq(rows []Event) {
    start := time.Now()
    defer func() {
        flushDurationSec.WithLabelValues("request").Observe(time.Since(start).Seconds())
    }()
    // 重试 3 次
    var err error
    for attempt := 0; attempt < 3; attempt++ {
        ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
        err = f.db.WithContext(ctx).Create(&rows).Error
        cancel()
        if err == nil {
            return
        }
        time.Sleep(time.Duration(100*(1<<attempt)) * time.Millisecond)
    }
    writeFailuresTotal.WithLabelValues("request").Inc()
    f.log.Error("log: batch insert request_logs failed after 3 retries",
        zap.Error(err), zap.Int("batch_size", len(rows)))
    // 不能再丢回 channel(可能死循环)。M1 决定:**丢弃**。
    // M2 加 DLQ(死信文件或外部队列)。
}

func (f *flusher) doFlushErr(rows []ErrorEvent) {
    start := time.Now()
    defer func() {
        flushDurationSec.WithLabelValues("error").Observe(time.Since(start).Seconds())
    }()
    var err error
    for attempt := 0; attempt < 3; attempt++ {
        ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
        err = f.db.WithContext(ctx).Create(&rows).Error
        cancel()
        if err == nil { return }
        time.Sleep(time.Duration(100*(1<<attempt)) * time.Millisecond)
    }
    writeFailuresTotal.WithLabelValues("error").Inc()
    f.log.Error("log: batch insert error_logs failed after 3 retries",
        zap.Error(err), zap.Int("batch_size", len(rows)))
}
```

### 4.4 非阻塞入队

```go
// internal/log/db_store.go(摘录)
func (s *dbStore) Write(ctx context.Context, e Event) {
    if e.ID == 0 {
        e.ID = s.idgen.Generate()
    }
    if e.CreatedAt.IsZero() {
        e.CreatedAt = s.clock.Now().UTC()
    }
    select {
    case s.flusher.chReq <- e:
        // ok
    default:
        droppedTotal.WithLabelValues("request").Inc()
        // 不打日志(高频路径)— 由 Prometheus alert 监控
    }
}

func (s *dbStore) WriteError(ctx context.Context, e ErrorEvent) {
    if e.ID == 0 { e.ID = s.idgen.Generate() }
    if e.CreatedAt.IsZero() { e.CreatedAt = s.clock.Now().UTC() }
    select {
    case s.flusher.chErr <- e:
    default:
        droppedTotal.WithLabelValues("error").Inc()
    }
}
```

**重点**:
- `select { case <-ch: default }` 是 Go 的零阻塞习语
- 不传 `ctx` 进 channel(传了 select 也无意义,channel 满即 default 走人)
- 调用方传 `nil ctx` 也 OK

### 4.5 优雅关停

```go
// internal/log/flusher.go(续)

func (f *flusher) close(ctx context.Context) error {
    // 1. 关闭 input channel — 不接收新事件
    close(f.chReq)
    close(f.chErr)
    // 2. 通知 worker 停止(已经 close 会自然 drain 完)
    close(f.stopCh)
    // 3. 等所有 worker 退出 — 受 ctx 控制
    done := make(chan struct{})
    go func() { f.wg.Wait(); close(done) }()
    select {
    case <-done:
        return nil
    case <-ctx.Done():
        f.log.Warn("log: flusher close timeout, some events may be lost")
        return ctx.Err()
    }
}
```

> **决策**:close channel 后再 close stopCh — `select` 在 channel 关闭后 `case <-chReq` 会立刻进入 ok=false 分支,drain 后 return。stopCh 是双保险(避免 channel 永远不关时 worker 不退出)。

**注意**:`Write` 调用方在 close 之后再写会 panic(write to closed channel)。约定调用方在 main.Shutdown 序列中**先停 server,再 close log store**,避免竞态。本 spec 在 `cmd/proapi` 的 shutdown 链中明确顺序(M1-01 已建好 LIFO 链)。

```go
// internal/log/partition_mysql.go
package log

import (
    "context"
    "fmt"
    "time"

    "gorm.io/gorm"
)

type mysqlPartitioner struct {
    db    *gorm.DB
    table string
}

// partitionName: p_2026_05
func mysqlPartitionName(t time.Time) string {
    return fmt.Sprintf("p_%04d_%02d", t.Year(), int(t.Month()))
}

func (p *mysqlPartitioner) Ensure(ctx context.Context, month time.Time) error {
    name := mysqlPartitionName(month)
    next := month.AddDate(0, 1, 0)

    exists, err := p.partitionExists(ctx, name)
    if err != nil {
        partitionEnsureTotal.WithLabelValues("error").Inc()
        return err
    }
    if exists {
        partitionEnsureTotal.WithLabelValues("exists").Inc()
        return nil
    }

    // 在 p_max 之前插入新分区:必须 REORGANIZE PARTITION
    // 假设当前结构是 ..., p_2026_05 LESS THAN (TO_DAYS('2026-06-01')), p_max LESS THAN MAXVALUE
    // 加 p_2026_06:
    //   ALTER TABLE request_logs REORGANIZE PARTITION p_max INTO (
    //       PARTITION p_2026_06 VALUES LESS THAN (TO_DAYS('2026-07-01')),
    //       PARTITION p_max     VALUES LESS THAN MAXVALUE
    //   )
    sql := fmt.Sprintf(
        "ALTER TABLE %s REORGANIZE PARTITION p_max INTO ("+
            "PARTITION %s VALUES LESS THAN (TO_DAYS('%s')), "+
            "PARTITION p_max VALUES LESS THAN MAXVALUE)",
        p.table, name, next.Format("2006-01-02"),
    )
    if err := p.db.WithContext(ctx).Exec(sql).Error; err != nil {
        partitionEnsureTotal.WithLabelValues("error").Inc()
        return fmt.Errorf("create partition %s: %w", name, err)
    }
    partitionEnsureTotal.WithLabelValues("created").Inc()
    return nil
}

func (p *mysqlPartitioner) partitionExists(ctx context.Context, name string) (bool, error) {
    var cnt int64
    err := p.db.WithContext(ctx).Raw(
        `SELECT COUNT(*) FROM information_schema.PARTITIONS 
         WHERE TABLE_SCHEMA = DATABASE() AND TABLE_NAME = ? AND PARTITION_NAME = ?`,
        p.table, name,
    ).Scan(&cnt).Error
    return cnt > 0, err
}
```

**关键决策**:
- `REORGANIZE PARTITION p_max INTO (...)` 是 MySQL 唯一能"在已有 MAXVALUE 分区前插入"的语法 — 直接 ADD 会报 `1481 MAXVALUE can only be used in last partition definition`
- REORGANIZE 是 **DDL 锁表**(InnoDB online DDL 支持 ADD,但 REORGANIZE 不支持 in-place)。**M1 接受**:执行时间在 < 1s 量级(空分区拆分),且每月只跑一次,生产可接受
- 若 `p_max` 已经有数据(应用没及时建分区时新数据落到 p_max),REORGANIZE 会很慢(要扫描)。**风险缓解**:每日凌晨 4 点定时 + 启动时预建 13 个月,基本不会让 p_max 有数据

#### 4.6.4 EnsurePartitions 主流程

```go
// internal/log/partition.go

func (s *dbStore) EnsurePartitions(ctx context.Context, start time.Time, months int) error {
    // 对齐到月初(UTC)
    startMonth := time.Date(start.UTC().Year(), start.UTC().Month(), 1, 0, 0, 0, 0, time.UTC)
    var firstErr error
    for i := 0; i <= months; i++ {
        m := startMonth.AddDate(0, i, 0)
        if err := s.partitioner.Ensure(ctx, m); err != nil {
            s.log.Error("log: ensure partition failed",
                zap.Time("month", m), zap.Error(err))
            if firstErr == nil { firstErr = err }
        }
    }
    return firstErr
}
```

#### 4.6.5 每日凌晨 4 点 cron

```go
// internal/log/partition.go(续)

// startPartitionCron 启动后台 goroutine,在每天 04:00 UTC 跑一次 EnsurePartitions(now, 12)。
//
// 实现细节:用 clock.Clock(便于测试),不引入第三方 cron 包。
func (s *dbStore) startPartitionCron(ctx context.Context) {
    s.cronWG.Add(1)
    go func() {
        defer s.cronWG.Done()
        for {
            next := nextCronAt(s.clock.Now(), 4, 0) // 下一个 04:00 UTC
            wait := next.Sub(s.clock.Now())
            select {
            case <-s.clock.NewTicker(wait).C():
                // tick(M1-01 的 Mock Clock 支持单 fire)
                ensureCtx, cancel := context.WithTimeout(ctx, 5*time.Minute)
                _ = s.EnsurePartitions(ensureCtx, s.clock.Now(), 12)
                cancel()
            case <-s.cronStop:
                return
            }
        }
    }()
}

// nextCronAt 计算今天/明天 hh:mm UTC 的最近一个时间点。
func nextCronAt(now time.Time, hour, minute int) time.Time {
    t := time.Date(now.UTC().Year(), now.UTC().Month(), now.UTC().Day(),
        hour, minute, 0, 0, time.UTC)
    if !t.After(now.UTC()) {
        t = t.AddDate(0, 0, 1)
    }
    return t
}
```

### 4.7 Query keyset 分页

#### 4.7.1 SQL 模板(MySQL / PG 共用,GORM 自动占位符化)

```sql
SELECT id, created_at, user_id, token_id, ..., trace_id
FROM request_logs
WHERE created_at >= ? AND created_at < ?
  -- 可选条件
  AND user_id = ?      -- if q.UserID != nil

  AND event_type = ?
  AND status_code = ?
  AND client_model LIKE ?  -- if q.ClientModel 含 '*'
```

#### 4.7.2 Cursor 格式

base64url-encode(`<RFC3339Nano>|<id十进制>`),例:

```
2026-05-21T03:14:15.926Z|7234567890123456789
→ MjAyNi0wNS0yMVQwMzoxNDoxNS45MjZafDcyMzQ1Njc4OTAxMjM0NTY3ODk=
```

```go
// internal/log/event.go(续)

func (c Cursor) String() string {
    raw := c.CreatedAt.UTC().Format(time.RFC3339Nano) + "|" +
        strconv.FormatInt(c.ID, 10)
    return base64.RawURLEncoding.EncodeToString([]byte(raw))
}

func ParseCursor(s string) (*Cursor, error) {
    b, err := base64.RawURLEncoding.DecodeString(s)
    if err != nil { return nil, ErrInvalidCursor }
    parts := strings.SplitN(string(b), "|", 2)
    if len(parts) != 2 { return nil, ErrInvalidCursor }
    t, err := time.Parse(time.RFC3339Nano, parts[0])
    if err != nil { return nil, ErrInvalidCursor }
    id, err := strconv.ParseInt(parts[1], 10, 64)
    if err != nil { return nil, ErrInvalidCursor }
    return &Cursor{CreatedAt: t.UTC(), ID: id}, nil
}

var ErrInvalidCursor = errors.New("log: invalid cursor")
```

#### 4.7.3 Query 实现(关键片段)

```go
// internal/log/query.go
package log

import (
    "context"
    "errors"
    "strings"
    "time"

    "gorm.io/gorm"
)

var (
    ErrTimeRangeRequired = errors.New("log: time range required")
    ErrTimeRangeTooWide  = errors.New("log: time range too wide (max 31 days)")
)

const maxPageSize = 200
const defaultPageSize = 50
const maxQueryRangeDays = 31

func (s *dbStore) Query(ctx context.Context, q Query) (QueryResult, error) {
    if q.From.IsZero() || q.To.IsZero() {
        return QueryResult{}, ErrTimeRangeRequired
    }
    if q.To.Sub(q.From) > maxQueryRangeDays*24*time.Hour {
        return QueryResult{}, ErrTimeRangeTooWide
    }
    if q.PageSize <= 0 { q.PageSize = defaultPageSize }
    if q.PageSize > maxPageSize { q.PageSize = maxPageSize }

    tx := s.db.WithContext(ctx).Model(&Event{}).
        Where("created_at >= ? AND created_at < ?", q.From, q.To)

    if q.UserID != nil    { tx = tx.Where("user_id = ?", *q.UserID) }
    if q.TokenID != nil   { tx = tx.Where("token_id = ?", *q.TokenID) }
    if q.ChannelID != nil { tx = tx.Where("channel_id = ?", *q.ChannelID) }
    if q.EventType != nil { tx = tx.Where("event_type = ?", *q.EventType) }
    if q.StatusCode != nil{ tx = tx.Where("status_code = ?", *q.StatusCode) }
    if q.TraceID != ""    { tx = tx.Where("trace_id = ?", q.TraceID) }
    if q.ClientModel != "" {
        if strings.ContainsRune(q.ClientModel, '*') {
            pat := strings.ReplaceAll(q.ClientModel, "*", "%")
            tx = tx.Where("client_model LIKE ?", pat)
        } else {
            tx = tx.Where("client_model = ?", q.ClientModel)
        }
    }
    if q.Cursor != nil {
        // (created_at, id) < (cursor) — 多列 tuple 比较
        tx = tx.Where(
            "(created_at, id) < (?, ?)",
            q.Cursor.CreatedAt, q.Cursor.ID,
        )
    }

    var items []Event
    err := tx.Order("created_at DESC, id DESC").
        Limit(q.PageSize + 1).  // 多取 1 条判断是否有下一页
        Find(&items).Error
    if err != nil { return QueryResult{}, err }

    res := QueryResult{Items: items}
    if len(items) > q.PageSize {
        res.Items = items[:q.PageSize]
        last := items[q.PageSize-1]
        res.NextCursor = &Cursor{CreatedAt: last.CreatedAt, ID: last.ID}
    }

    // 只有小页才返回 Total(避免 COUNT 大查询)
    if q.PageSize <= 50 && q.Cursor == nil {
        var total int64
        if err := tx.Session(&gorm.Session{}).Limit(-1).Offset(-1).Count(&total).Error; err == nil {
            res.Total = &total
        }
    }
    return res, nil
}
```

> **多列 tuple 比较 `(a, b) < (?, ?)`**:MySQL 5.7+ 与 PG 全支持,等价于 `a < ? OR (a = ? AND b < ?)` 但更紧凑。GORM 直接传字符串模板即可。

#### 4.7.4 时间范围约束

`maxQueryRangeDays = 31`:任意 Query 不允许 > 31 天。理由:
- 单分区(月)≈ 31 天,跨多分区时优化器仍 OK,但 > 90 天的范围会让分区裁剪失效,扫描成本巨大
- 31 天满足"看上月所有日志"用例
- 真要长跨度看历史 → CSV 导出走 ExportCSV 接口(单次最多 1M 行)

`ExportCSV` 不受此约束(允许任意范围,但有 maxRows 限制)。

```go
func (s *dbStore) StatsOverview(ctx context.Context, q OverviewQuery) (Overview, error) {
    if q.From.IsZero() || q.To.IsZero() {

    var out Overview

            ReqCnt   int64
            ErrCnt   int64
            Quota    int64
            AvgLat   float64
        }

            Select(`COUNT(*) AS req_cnt,
                    SUM(CASE WHEN status_code >= 400 OR error_code != 0 THEN 1 ELSE 0 END) AS err_cnt,
                    COALESCE(SUM(total_quota), 0) AS quota,
                    COALESCE(AVG(latency_ms), 0) AS avg_lat`).
            Scan(&row).Error
        if err != nil { return err }
        out.RequestCount = row.ReqCnt
        out.ErrorCount = row.ErrCnt
        out.TotalQuota = row.Quota
        out.AvgLatencyMS = row.AvgLat
        if row.ReqCnt > 0 {
            out.ErrorRate = float64(row.ErrCnt) / float64(row.ReqCnt)
        }
        return nil
    })

    // 2. usage_count(event_type=1 且 status<400)
    eg.Go(func() error {
        var n int64

            Where("event_type = 1 AND status_code < 400").
            Count(&n).Error
        if err != nil { return err }
        out.UsageCount = n
        return nil

    // 3. active users
    eg.Go(func() error {
        var n int64
        err := s.baseQuery(q).
            Distinct("user_id").
            Count(&n).Error
        if err != nil { return err }
        out.ActiveUsers = n
        return nil

        if err != nil { return err }
```

#### 4.8.2 timeseries

按 granularity 用方言函数:

- **MySQL**:`DATE_FORMAT(created_at, '%Y-%m-%d %H:00:00')`(hour)/ `%Y-%m-%d`(day)
- **PG**:`DATE_TRUNC('hour', created_at)` / `DATE_TRUNC('day', created_at)`

```go
func (s *dbStore) StatsTimeseries(ctx context.Context, q TimeseriesQuery) (Timeseries, error) {
    if q.From.IsZero() || q.To.IsZero() { return Timeseries{}, ErrTimeRangeRequired }
    if q.Granularity != "hour" && q.Granularity != "day" {
        return Timeseries{}, errors.New("invalid granularity")
    }
    bucketExpr := s.bucketExpr(q.Granularity)

    sql := fmt.Sprintf(`
        SELECT %s AS bucket,
               COUNT(*)                                                      AS request_count,
               SUM(CASE WHEN status_code>=400 OR error_code!=0 THEN 1 ELSE 0 END) AS error_count,
               COALESCE(SUM(total_quota), 0)                                 AS total_quota,
               COALESCE(SUM(input_tokens), 0)                                AS input_tokens,
               COALESCE(SUM(output_tokens), 0)                               AS output_tokens,
               COALESCE(AVG(latency_ms), 0)                                  AS avg_latency_ms
        FROM request_logs
        WHERE created_at >= ? AND created_at < ?`, bucketExpr)

    args := []any{q.From, q.To}
    if q.UserID != nil    { sql += " AND user_id = ?";    args = append(args, *q.UserID) }
    if q.ChannelID != nil { sql += " AND channel_id = ?"; args = append(args, *q.ChannelID) }
    if q.Model != "" {
        if strings.ContainsRune(q.Model, '*') {
            sql += " AND client_model LIKE ?"; args = append(args, strings.ReplaceAll(q.Model, "*", "%"))
        } else {
            sql += " AND client_model = ?";    args = append(args, q.Model)
        }
    }
    sql += " GROUP BY bucket ORDER BY bucket ASC"

    var rows []TimeseriesPoint
    if err := s.db.WithContext(ctx).Raw(sql, args...).Scan(&rows).Error; err != nil {
        return Timeseries{}, err
    }
    return Timeseries{Granularity: q.Granularity, Points: rows}, nil
}

func (s *dbStore) bucketExpr(gran string) string {
    if s.driver == "postgres" {
        return fmt.Sprintf("DATE_TRUNC('%s', created_at)", gran)
    }
    // MySQL
    if gran == "hour" {
        return "DATE_FORMAT(created_at, '%Y-%m-%d %H:00:00')"
    }
    return "DATE_FORMAT(created_at, '%Y-%m-%d')"
}
```

> **空桶填充**:DB 返回的 buckets 不含没有数据的 hour/day。**M1 决策**:前端补 0。后端不补,响应轻便。

```go
func (s *dbStore) statsBy(ctx context.Context, q GroupQuery, keyCol string) (GroupResult, error) {
    if q.From.IsZero() || q.To.IsZero() { return GroupResult{}, ErrTimeRangeRequired }
    if q.Limit <= 0 { q.Limit = 100 }
    if q.Limit > 500 { q.Limit = 500 }

    orderBy := "request_count DESC"
    switch q.OrderBy {
    case "quota":    orderBy = "total_quota DESC"
    case "tokens":   orderBy = "input_tokens + output_tokens DESC"
    case "requests": orderBy = "request_count DESC"
    }

    sql := fmt.Sprintf(`
        SELECT CAST(%s AS CHAR) AS key,
               COUNT(*) AS request_count,
               SUM(CASE WHEN status_code>=400 OR error_code!=0 THEN 1 ELSE 0 END) AS error_count,
               COALESCE(SUM(total_quota), 0) AS total_quota,
               COALESCE(SUM(input_tokens), 0) AS input_tokens,
               COALESCE(SUM(output_tokens), 0) AS output_tokens,
               COALESCE(AVG(latency_ms), 0) AS avg_latency_ms
        FROM request_logs
        WHERE created_at >= ? AND created_at < ?`,
        keyCol)
    args := []any{q.From, q.To}
    if q.UserID != nil { sql += " AND user_id = ?"; args = append(args, *q.UserID) }
    sql += fmt.Sprintf(` GROUP BY %s ORDER BY %s LIMIT ?`, keyCol, orderBy)
    args = append(args, q.Limit)

    var rows []GroupRow
    if err := s.db.WithContext(ctx).Raw(sql, args...).Scan(&rows).Error; err != nil {
        return GroupResult{}, err
    }

    // total = 全部 key 数(便于前端显示"共 X 类")
    var total int64
    s.db.WithContext(ctx).Raw(
        fmt.Sprintf(`SELECT COUNT(DISTINCT %s) FROM request_logs 
                     WHERE created_at >= ? AND created_at < ?`, keyCol),
        q.From, q.To).Scan(&total)

    return GroupResult{Rows: rows, Total: total}, nil
}
```

### 4.9 CSV 流式导出

#### 4.9.1 流程

```
1. Header: 设置 Content-Type: text/csv; charset=utf-8
            Content-Disposition: attachment; filename="request_logs_<from>_<to>.csv"
            Transfer-Encoding: chunked
2. 写表头一行
3. Cursor 翻页(batch 1000),每页 Encode 后写 ResponseWriter + Flush
4. 累计行数到达 maxRows 时:
   - 写一行 `_TRUNCATED,...,reason=row_limit_exceeded`
   - return
5. 全部写完,结束
```

#### 4.9.2 实现

```go
// internal/log/csv_export.go
package log

import (
    "context"
    "encoding/csv"
    "fmt"
    "io"
    "strconv"
    "time"
)

const defaultExportMaxRows = 1_000_000

var csvHeaders = []string{
    "id", "created_at", "user_id", "token_id", "channel_id",
    "event_type", "client_model", "upstream_model", "protocol", "endpoint",
    "ip", "status_code", "latency_ms", "ttft_ms", "stream",
    "input_tokens", "output_tokens", "cached_tokens", "reasoning_tokens",
    "total_quota", "billing_input_ratio", "billing_output_ratio", "billing_group_ratio",
    "error_code", "error_msg", "trace_id",
}

func (s *dbStore) ExportCSV(ctx context.Context, q Query, w io.Writer) (int64, error) {
    if q.From.IsZero() || q.To.IsZero() {
        return 0, ErrTimeRangeRequired
    }
    maxRows := int64(defaultExportMaxRows)
    if v := s.setting.GetInt(ctx, "log.export_max_rows", 0); v > 0 {
        maxRows = int64(v)
    }

    cw := csv.NewWriter(w)
    defer cw.Flush()

    if err := cw.Write(csvHeaders); err != nil { return 0, err }
    cw.Flush()
    if f, ok := w.(http.Flusher); ok { f.Flush() }

    var written int64
    pageSize := 1000
    q.PageSize = pageSize
    q.Cursor = nil

    for {
        page, err := s.Query(ctx, q)
        if err != nil { return written, err }
        for _, e := range page.Items {
            if written >= maxRows {
                _ = cw.Write([]string{"_TRUNCATED", "", "", "", "", "", "", "", "", "",
                    "", "", "", "", "", "", "", "", "", "", "", "", "", "", "row_limit_exceeded", ""})
                cw.Flush()
                return written, nil
            }
            if err := cw.Write(eventToCSVRow(e)); err != nil {
                return written, err
            }
            written++
        }
        cw.Flush()
        if f, ok := w.(http.Flusher); ok { f.Flush() }
        if page.NextCursor == nil { break }
        q.Cursor = page.NextCursor
    }
    return written, nil
}

func eventToCSVRow(e Event) []string {
    return []string{
        strconv.FormatInt(e.ID, 10),
        e.CreatedAt.UTC().Format(time.RFC3339Nano),
        strconv.FormatInt(e.UserID, 10),
        strconv.FormatInt(e.TokenID, 10),
        nullableInt64(e.ChannelID),
        strconv.Itoa(int(e.EventType)),
        e.ClientModel,
        e.UpstreamModel,
        e.Protocol,
        e.Endpoint,
        e.IP,
        strconv.Itoa(e.StatusCode),
        strconv.Itoa(e.LatencyMS),
        strconv.Itoa(e.TTFTMS),
        strconv.FormatBool(e.Stream),
        strconv.Itoa(e.InputTokens),
        strconv.Itoa(e.OutputTokens),
        strconv.Itoa(e.CachedTokens),
        strconv.Itoa(e.ReasoningTokens),
        strconv.FormatInt(e.TotalQuota, 10),
        fmt.Sprintf("%.4f", e.BillingInputRatio),
        fmt.Sprintf("%.4f", e.BillingOutputRatio),
        fmt.Sprintf("%.4f", e.BillingGroupRatio),
        strconv.Itoa(e.ErrorCode),
        e.ErrorMsg,
        e.TraceID,
    }
}

func nullableInt64(p *int64) string {
    if p == nil { return "" }
    return strconv.FormatInt(*p, 10)
}
```

> **超大查询风险**:1M 行 × 平均 200 字节 = 200MB。流式输出 + 1000 行 chunk + 立即 flush,Go HTTP server 内存压力 < 5MB(一个 batch 缓冲)。

### 5.4 query string 解析

```go
// internal/server/handler/log/admin.go(摘录)
func parseQuery(c *gin.Context) (log.Query, error) {
    var q log.Query
    var err error

    // 必填时间范围
    fromStr := c.Query("from")
    toStr   := c.Query("to")
    if fromStr == "" || toStr == "" {
        return q, errors.New("from and to are required")
    }
    if q.From, err = time.Parse(time.RFC3339, fromStr); err != nil {
        return q, fmt.Errorf("invalid from: %w", err)
    }
    if q.To, err = time.Parse(time.RFC3339, toStr); err != nil {
        return q, fmt.Errorf("invalid to: %w", err)
    }
    q.From = q.From.UTC()
    q.To = q.To.UTC()
    if !q.To.After(q.From) {
        return q, errors.New("to must be after from")
    }

    if s := c.Query("user_id"); s != "" {
        v, err := strconv.ParseInt(s, 10, 64)
        if err != nil { return q, fmt.Errorf("user_id: %w", err) }
        q.UserID = &v
    }
    if s := c.Query("token_id"); s != "" {
        v, _ := strconv.ParseInt(s, 10, 64); q.TokenID = &v
    }
    if s := c.Query("channel_id"); s != "" {
        v, _ := strconv.ParseInt(s, 10, 64); q.ChannelID = &v
    }
    if s := c.Query("event_type"); s != "" {
        v, _ := strconv.Atoi(s); et := int8(v); q.EventType = &et
    }
    if s := c.Query("status_code"); s != "" {
        v, _ := strconv.Atoi(s); q.StatusCode = &v
    }
    q.ClientModel = c.Query("client_model")
    q.TraceID = c.Query("trace_id")

    if s := c.Query("page_size"); s != "" {
        v, _ := strconv.Atoi(s); q.PageSize = v
    }
    if s := c.Query("cursor"); s != "" {
        cur, err := log.ParseCursor(s)
        if err != nil { return q, fmt.Errorf("cursor: %w", err) }
        q.Cursor = cur
    }
    return q, nil
}
```

```go
package logh

import (
    "net/http"
    "strconv"
    "time"

    "github.com/gin-gonic/gin"
    "github.com/proapi/proapi/internal/log"
    "github.com/proapi/proapi/internal/server/middleware"
    "github.com/proapi/proapi/pkg/apierr"
)

type Admin struct {
    log        log.Store
    channelSvc ChannelNameLooker
    userSvc    UserNameLooker
}

type ChannelNameLooker interface {
    NamesByIDs(ctx context.Context, ids []int64) map[int64]string
}
type UserNameLooker interface {
    UsernamesByIDs(ctx context.Context, ids []int64) map[int64]string
}

func NewAdmin(s log.Store, ch ChannelNameLooker, u UserNameLooker) *Admin {
    return &Admin{log: s, channelSvc: ch, userSvc: u}
}

func (h *Admin) Register(g *gin.RouterGroup) {
    g.GET("/logs/requests", h.QueryRequests)
    g.GET("/logs/errors",   h.QueryErrors)
    g.GET("/logs/audit",    h.QueryAudits)
    g.GET("/stats/overview",    h.StatsOverview)
    g.GET("/stats/timeseries",  h.StatsTimeseries)
    g.GET("/stats/by_model",    h.StatsByModel)
    g.GET("/stats/by_channel",  h.StatsByChannel)
    g.GET("/stats/by_user",     h.StatsByUser)
    g.GET("/stats/export",      h.ExportCSV)
}

func (h *Admin) QueryRequests(c *gin.Context) {
    q, err := parseQuery(c)
    if err != nil { middleware.SetErr(c, apierr.New(apierr.CodeInvalidParam, err.Error())); return }
    res, err := h.log.Query(c, q)
    if err != nil { middleware.SetErr(c, mapStoreErr(err)); return }
    c.JSON(http.StatusOK, res)
}

// QueryErrors / QueryAudits / StatsOverview / StatsTimeseries 略
// 模板都是:parseQuery → call store → map err → c.JSON

func (h *Admin) StatsByChannel(c *gin.Context) {
    q, err := parseGroupQuery(c)
    if err != nil { middleware.SetErr(c, apierr.New(apierr.CodeInvalidParam, err.Error())); return }
    res, err := h.log.StatsByChannel(c, q)
    if err != nil { middleware.SetErr(c, mapStoreErr(err)); return }
    // 填 label
    ids := make([]int64, 0, len(res.Rows))
    for _, r := range res.Rows {
        if id, e := strconv.ParseInt(r.Key, 10, 64); e == nil { ids = append(ids, id) }
    }
    name := h.channelSvc.NamesByIDs(c, ids)
    for i := range res.Rows {
        if id, e := strconv.ParseInt(res.Rows[i].Key, 10, 64); e == nil {
            res.Rows[i].Label = name[id]
        }
    }
    c.JSON(http.StatusOK, res)
}

func (h *Admin) ExportCSV(c *gin.Context) {
    q, err := parseQuery(c)
    if err != nil { middleware.SetErr(c, apierr.New(apierr.CodeInvalidParam, err.Error())); return }
    q.PageSize = 0  // 走 export 内部分页
    fn := fmt.Sprintf("request_logs_%s_%s.csv",
        q.From.Format("20060102"), q.To.Format("20060102"))
    c.Header("Content-Type", "text/csv; charset=utf-8")
    c.Header("Content-Disposition", fmt.Sprintf(`attachment; filename="%s"`, fn))
    c.Header("X-Accel-Buffering", "no") // nginx 不缓冲
    n, err := h.log.ExportCSV(c, q, c.Writer)
    if err != nil {
        // 已经开始写流后报错只能记录,不能改 status
        // 中间会写出 "_ERROR" 行作为 trailer 留给客户端识别
        return
    }
    c.Header("X-Total-Rows", strconv.FormatInt(n, 10))
}

func mapStoreErr(err error) *apierr.Error {
    switch {
    case errors.Is(err, log.ErrTimeRangeRequired):
        return apierr.New(apierr.CodeInvalidParam, "time range (from/to) required")
    case errors.Is(err, log.ErrTimeRangeTooWide):
        return apierr.New(apierr.CodeInvalidParam, "time range too wide (max 31 days)")
    case errors.Is(err, log.ErrInvalidCursor):
        return apierr.New(apierr.CodeInvalidParam, "invalid cursor")
    case errors.Is(err, log.ErrCHNotImplemented):
        return apierr.New(apierr.CodeInternal, "clickhouse backend not implemented")
    default:
        return apierr.New(apierr.CodeDatabase, err.Error())
    }
}
```

### 6.3 异步写日志的最终一致性

- relay 链路在 `defer` 内 `log.Store.Write`,即便 channel 满丢失也不影响请求
- 用户在前台刷新日志,可能因 batch 未 flush 看不到最近 1 秒的请求
- **接受度**:前端 UI 显示"日志可能延迟 1-2 秒,请稍候刷新"提示
- 错误路径(error_logs)同样异步,故"用户看到 500 但 error_logs 表暂无"是合法状态

### 11.2 被依赖(谁需要本 spec)

| 模块 spec | 用本 spec 的什么 |
|---|---|
| M1-04 适配器层 | 不直接用,但 relay 调用方需要 `log.Store.WriteError` 记录上游错误 |
| M1-05 渠道调度 | breaker 状态变化时 `log.Store.WriteError`(error_type="channel_breaker") |
| M1-06 计费 | reserve/commit/refund 异常时 `log.Store.WriteError`;每次成功请求最终 `log.Store.Write(Event{event_type=1})` |
| M1-07 限流 | 限流命中时 `log.Store.WriteError`(error_type="rate_limit") |
| **M1-09 后台前端** | 全部 8 个 admin 接口 |
| **M1-10 用户前台** | 2 个 user 接口 |
| M1-12 系统设置 | 接口配置覆盖时调 `setting.Put` — 本 spec 读 `log.*` setting |

### 11.3 接口适配点

```go
// internal/log/lookup.go(在 wire_log.go 同包,但分文件)
package log

import "context"

// ChannelNameLooker / UserNameLooker — minimal interface
// 让 handler 不必导入 channel / user 包(避免循环依赖)。
// M1-05 / M1-02 的实现满足这些接口。

type ChannelNameLooker interface {
    NamesByIDs(ctx context.Context, ids []int64) map[int64]string
}

type UserNameLooker interface {
    UsernamesByIDs(ctx context.Context, ids []int64) map[int64]string
}

// NoopChannelLooker / NoopUserLooker — 测试用
type NoopChannelLooker struct{}
func (NoopChannelLooker) NamesByIDs(context.Context, []int64) map[int64]string { return nil }

type NoopUserLooker struct{}
func (NoopUserLooker) UsernamesByIDs(context.Context, []int64) map[int64]string { return nil }
```

handler 包(`internal/server/handler/log`)从 `log` 包 import 接口,从 `app.Application` 注入实现。
